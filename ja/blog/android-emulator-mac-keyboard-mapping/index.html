MacのAndroidエミュレータでキーマッピングする: 画面上のボタンとゲーム別の配置

著者 Ryan Gibo · 2026年10月27日

Androidのゲームの多くは、指を前提にしています。Macにはキーボードとマウスがあり、コントローラーを持っている人もいます。トラックパッドを何時間も叩き続けるのは、すぐ疲れます。SiliconPlay はゲーム画面の上にボタンを置き、そのボタンをキーへ結びます。MacのAndroidエミュレータにおけるキーマッピングとは、そのことです。キーやスティックが、選んだ場所のタッチになります。

SiliconPlayが動くのはApple Siliconだけで、M1からM5、そして同じ系統の新しいチップです。Apple SiliconのARMコアでネイティブに動きます。私はmacOS Tahoeで試しています。ほかのmacOSの場合は、何が起きたかを 知らせてください。

キーを使うまでは、直接タッチです

直接タッチが初期状態です。ポインタは指として働きます。メニューやショップ、キーマップのないアプリには、この方が向いています。知っているゲームが前面に来ると、SiliconPlayはコミュニティのプリセットを提案できます。そのプリセットは、受け入れるまでオフのままです。アプリを開いただけでキーマップが読み込まれることはありません。

Androidの画像をクリックすると、キーボードはキーマップへ向かいます。テキスト欄にフォーカスがあると、ツールバーは Typing と表示し、キーはボタンではなくAndroidへ入ります。F12またはCommand-K で Typing と Game keys を切り替えます。Commandキーを使うメニューのショートカットは、macOS側に残ります。

SiliconPlayのウィンドウにフォーカスがあるあいだも、キーは使えます。アプリがエミュレータ自身のウィンドウを初めて追いかけるとき、macOSは Accessibility を求めます。許可するまでは、SiliconPlayのウィンドウにフォーカスを置いたままにしてください。キーは届きます。

初期配置: MMORPG (WASD)

アプリに同梱されている汎用の配置の名前は MMORPG (WASD) です。特定のpackageには結び付いていないので、自動では提案されません。どのゲームにも適用して、ずれているところを直してください。スティックは自分のボタンの中央に触れ、そのキーを押しているあいだ外側へずれます。離すと中央へ戻ります。

このプリセットのメモは、エディタで調整するように書いてあります。位置はキー配置の出発点として扱ってください。ゲーム画面に対する割合で、0から1です。原点は左上なので、ウィンドウの大きさが変わっても釣り合います。

ボタンをゲームの絵に合うまで動かす

Edit layout を開くと、キーマップのエディタになります。ボタンをドラッグして移動します。クリックすると、キーやマウスボタンを割り当て直せます。gold dot をドラッグすると大きさが変わります。WASDのジョイスティック、カメラのドラッグ、タップ、長押し、スワイプ、リピートを足せます。Done で保存します。Cancel は、編集を開いたときのプロファイルに戻します。割り当て直しの途中なら、Escape でキーの取り込みを取り消します。

別のエミュレータウィンドウには、ガラスのバブルが付いてきます。バブルをドラッグすると移動します。クリックすると、オーバーレイ、不透明度、大きさ、編集、リセットが出ます。その位置はプロファイルに保存されます。Command-Shift-G でオーバーレイの表示を切り替えます。絵の空いているところを押すと、そのままゲームをクリックします。

F10は直接タッチへ切り替えます。メニューが、割り当て済みのボタンではなく本物の指を求めているときの方が簡単です。仮想の指が押しっぱなしになったら、Shift-Escape で全部離します。

コントローラーも同じボタンを押します

一つのチップは、複数の入力を受け取れます。初期配置では、skill 1 が 1 キーと gamepad X、ジャンプが Space と gamepad B です。割り当て直すときは、face buttons、shoulders、triggers、D-pad、menu、options も結び付けられます。コントローラーは第二の操作体系ではありません。キーボードと同じ画面上のボタンを押します。

ゲームごとの配置

アプリによっては、packageで照合される専用のプリセットがあります。そのゲームが前面に来ると、SiliconPlayは提案して待ちます。受け入れてから、絵に合っていないものをドラッグしてください。これらのファイルの文言では、コミュニティプリセットと呼んでいます。

Minecraftは、汎用ではない配置の分かりやすい例です。このプリセットは、移動にWASD、壊すのに左クリック、使うのに右クリック、ジャンプに Space、インベントリに E、ホットバーに1から3、視点にマウスの右ボタンを使います。ボタンが別の隅にあるゲームには、画面下のMMORPGの並びではなく、こうした合わせ込みが必要です。

同じビルドには、Genshin Impact、Roblox、Call of Duty Mobile、Clash of Clans のプリセットもあります。一つの配置が全部に合うとは言いません。提案を受け入れ、少し遊んで、チップを動かしてください。

ネットでキーマップを探す

頼りになるのは、アプリの中にあるコピーです。誰かが公開した配置を見つける場合、それはSiliconPlayのキーマップでなければなりません。format id が stardroid.keymap のJSONです。その形式として正しくないJSONは拒否されます。共有ファイルの位置は、ほかの人の画面向けに描かれています。エディタを開いて、自分の画面にボタンを合わせてください。

Pro Mode はツールバー、View メニュー、Settings にあります。オンにすると、メインウィンドウにハードウェア、キーマップ、診断が出ます。自分でオンにするまでオフです。エミュレータウィンドウのバブルには、編集、オーバーレイ、不透明度、大きさ、リセットが残ります。

質問

SiliconPlayはどのMacで動きますか。

AppleシリコンのMacで動きます。M1、M2、M3、M4、M5で、Pro、Max、Ultraも含みます。

キーマップは必須ですか。

必須ではありません。直接タッチが初期状態です。提案されたプリセットは、受け入れるまでオフのままです。

コントローラーは使えますか。

使えます。ゲームパッドのボタンは、キーボードと同じ画面上のチップを押します。MMORPGの配置では、いくつかのスキルとジャンプがすでに割り当てられています。

自分のゲーム用のキーマップはどこにありますか。

アプリが提案するプリセットを使うか、MMORPG (WASD) を自分で適用して編集します。ほかの場所のファイルは、正しい stardroid.keymap のJSONでなければなりません。
