Mac M1・M4でAndroidエミュレーターを使う：導入手順

著者 Ryan Gibo · 2026年10月28日

「Mac M1 Android エミュレーター」や「Mac M4 Android エミュレーター」で検索すると、Apple Silicon以前に書かれた情報がたくさん出てきます。ここでは短く、いまの手順をまとめます。Mチップ搭載のMacで、私がApple Silicon向けに作っているSiliconPlayを使ってAndroidのゲームやアプリを動かす方法です。

インストールするもの

SiliconPlayの中身はGoogle公式のAndroid Emulatorで、MacのARMコア上でネイティブに動きます。その周りのMacアプリ、つまりインターフェースと操作の割り当ては、私がゼロから書きました。Apple Silicon専用で、M1からM5まで対応し、macOS Tahoeで動作を確認しています。

必要なもの

  • M1、M2、M3、M4、M5チップ搭載のMac（Pro、Max、Ultraを含む）。
  • macOS Tahoe。私が動作を確認したバージョンです。
  • Google Playからインストールする場合はGoogleアカウント。

導入手順

  1. SiliconPlay.dmgをダウンロードします。
  2. DMGを開き、SiliconPlayを「アプリケーション」にドラッグします。
  3. SiliconPlayを開き、Androidを起動します。
  4. Google Playにログインして、ゲームやアプリを入れます。APKファイルを入れるときはCommand-Iを押します。
  5. Androidの画面をクリックします。初期設定は直接タッチです。キーで遊ぶなら、SiliconPlayがゲームに合わせて提案するプリセットを受け入れるか、MMORPG (WASD)を適用してボタンを動かします。

Mac版SiliconPlayをダウンロード

最初に覚えたいショートカット

  • Command-I：APKを取り込み、Androidへインストールします。
  • F12、またはCommand-K：Typing と Game keys を切り替えます。
  • Command-Shift-G：画面上のゲームボタンを表示／非表示にします。
  • Escape：全画面を抜けます。全画面でないときはAndroid Backです。
  • Shift-Escape：仮想の指をすべて離します。

M1とM4で何が変わる？

アプリはM1からM5まで、どのチップでも同じです。チップ別のベンチマークは公開していないので、M1やM4の数値は書きません。新しいチップほど余裕があり、重い3Dゲームで差が出やすくなります。カクつくときは、まずゲーム内のグラフィック設定を下げてください。ARM版がないアプリはどのチップでも動きませんが、いまのアプリの多くはARM版を含んでいます。

質問

Mac M1で動きますか？

はい。M1、M2、M3、M4、M5に対応し、Pro、Max、Ultraも含みます。

必要なmacOSのバージョンは？

SiliconPlayはmacOS Tahoeで動作を確認しています。ほかのバージョンで挙動が違ったら教えてください。

Googleのエミュレーターですか？

中身はそうです。Google公式のAndroid Emulatorです。インターフェースと操作の割り当てはSiliconPlay独自で、ゼロから書いています。

rootは必要ですか？

いいえ。rootはオプションで、初期状態ではオフです。必要な開発者のために用意しています。
