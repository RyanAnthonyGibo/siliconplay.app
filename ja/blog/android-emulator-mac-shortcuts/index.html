Mac版Androidのショートカット: SiliconPlayのキーボード一覧

著者 Ryan Gibo · 2026年10月27日

これはMac上の SiliconPlay のキーボードショートカット一覧です。アプリ本体（version 1.0.0, build 2）から取り、Command-I は別に私が確認しました。ほかのエミュレータのショートカットで空きを埋めてはいません。確認できなかった組み合わせは作っていないので、ここにありません。

SiliconPlayはApple Silicon専用です。M1、M2、M3、M4、M5と、同じ系統の新しいチップです。Apple SiliconのARMコアでネイティブに動きます。私はmacOS Tahoeで試しています。ほかのmacOSで様子が違うときは、教えてください。

キーはどこへ行くか

Androidの画像をクリックすると、キーボードはキーマップへ向かいます。CommandキーのメニューショートカットはmacOSに残り、ゲームへは打たれません。テキスト欄にフォーカスがあると、ツールバーが Typing になり、キーボードは文字としてAndroidへ入ります。

まだ編集していないときの初期キーマップ

キーマップが載るまで、Game keys はほとんど役に立ちません。汎用プリセットは MMORPG (WASD) です。一つのゲームには結び付いていません。適用してから、ボタンを動かしてください。編集の手順は Macのキーマッピング にまとめてあります。そのファイルの割り当ては次のとおりです。

ゲーム別のプリセットは、受け入れたときにこちらを置き換えます。たとえばMinecraftのプリセットは、JとMの代わりに、left click で break し、E で inventory を開きます。提案を受け入れるまでは直接タッチのままで、これらの Game keys は読み込まれません。

質問

文字入力とゲームキーの切り替えは何ですか。

F12またはCommand-Kです。Game keys はキーマップを使います。Typing はキーボードをAndroidへ送ります。テキスト欄は自分で Typing に切り替わります。

Escapeは何をしますか。

全画面を抜けます。ウィンドウが全画面でないとき、表示にフォーカスがあると Escape は Android Back です。Shift-Escape は仮想の指をすべて離します。割り当て直しの途中では、Escape が取り込みを取り消します。

これがアプリのショートカットの全部ですか。

Command-IはAPKを取り込んでAndroidへインストールします。表の残りは、1.0.0のヘルプ文が書き出している組み合わせと、初期キーマップです。Shortcutsの一覧には、このビルドで読めるキー文字列のない操作名もいくつかあります。その組み合わせはアプリで確認してください。

どのMacで動きますか。

AppleシリコンのMacで動きます。M1、M2、M3、M4、M5で、Pro、Max、Ultraも含みます。
