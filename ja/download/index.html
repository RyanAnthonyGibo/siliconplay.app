Mac版SiliconPlayをダウンロード

ダウンロードを準備しています…

SiliconPlay は M1 から M6 の Apple silicon Mac 向けの無料 Android エミュレーターです。ファイルは SiliconPlay.dmg、バージョン 1.1.2 です。DMG は Mac アプリです。Android 本体は最初に開いたときにダウンロードされます。

Mac版SiliconPlayをダウンロード

ファイルが届いたあと

  1. DMG を開き、SiliconPlay をアプリケーションにドラッグします。
  2. SiliconPlay を開きます。初回は Android SDK のライセンスに同意し、Apple silicon 向けエミュレーター、platform-tools、Play arm64 イメージを取得します。emulator、adb、sdkmanager のある SDK がすでにある場合は、そのフォルダを指定できます。
  3. Android 16 のタブレット（1920×1080、320 dpi、横向き）が起動したら、Google Play に入るか APK を 1 つ入れます。

必要なもの

  • Apple silicon の Mac。M1 から M6。Pro、Max、Ultra を含みます。
  • macOS Tahoe と macOS 27 Golden Gate で確認しています。別の版なら試し、何が起きたか教えてください。
  • Intel Macs には対応していません。

ショートカット。最初は Cmd+I

  • Cmd+I は Android が動いているときに APK を 1 つ入れます。メニューでは Command-I です。ドラッグ＆ドロップも同じインストールです。
  • F12 または Command-K で、文字入力とゲームキーを切り替えます。
  • F10 は、ダイアログが指を求めるときの直接タッチです。
  • Command-Shift-G は画面上のボタンを表示または非表示にします。
  • Shift-Escape は押しっぱなしの仮想指を離します。
  • Escape はフルスクリーンを終了します。フルスクリーン外では、画面にフォーカスがあるあいだ Android の戻るです。

JDK がないと止まると、macOS は /usr/bin/java のスタブを見せています。メッセージは brew install openjdk@17 を指します。入れてからパッケージの手順をやり直してください。長い手順はブログに、各ツールの位置は 比較.
