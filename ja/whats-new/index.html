SiliconPlay 1.1.2の新機能

バージョン1.1.2（ビルド5）・Apple Silicon M1〜M6・2026年11月20日

SiliconPlay 1.1.2は、Apple Silicon Mac向けAndroidエミュレーターの無料アップデートです。自動で最新の状態を保つようになり、起動するとすぐにメインウインドウ全体が表示され、新しいインスタンス一覧はクリックしたとおりに反応します。

Mac版SiliconPlay 1.1.2をダウンロード

1.1.2：なめらかなスクロールと、皆さんのログから生まれた修正

バージョン1.1.2（ビルド5）は、ユーザーから届いたログをもとに作られ、スクロールとズームの新しい操作が加わりました。

  • macOS Sequoia以前でAndroidがより確実に起動します。最新のAndroid Emulatorがうまく起動しない場合、SiliconPlayはその横に置いたテスト済みのエミュレーターを使います。
  • Androidの起動中にグラフィックスのエラーが繰り返し出ると、SiliconPlayが自動でより安全なグラフィックスモードに切り替え、お知らせします。
  • Androidが単に停止しただけのときに「ポートが使用中」と誤って表示されることがなくなりました。
  • ラジアルメニューに、マウスホイールとトラックパッド用の自動・ピンチ・スクロールモードを追加。自動はアプリではスクロール、ゲームではピンチズームします。
  • トラックパッドのスクロールがなめらかになり、Androidの起動直後から指の動きにぴったりついてきます。指を離してもリストは慣性で流れ続けます。
  • スクロールとピンチの感度：ラジアルメニューのSpeedで0.25×〜3×に調整でき、設定にはそれぞれのスライダーと1×に戻すResetがあります。
  • インスタンスの停止がより安定しました。SiliconPlayはAndroidが自分で終了するのを待ってから閉じます。

1.1.1：Androidの起動がより確実に

バージョン1.1.1（ビルド4）は修正アップデートです。特にmacOS Sequoia以前や、Android Emulatorが新しいバージョンに自動更新されたあとに、起動中に「could not start」で止まっていたMacで、Androidが起動しやすくなるはずです。

  • Androidを起動する前に、SiliconPlayはAndroid Emulatorのバージョンを読み取ります。macOS Sequoia以前で、テスト済みより新しいエミュレータの場合は、OpenGL ESグラフィックモードで起動します。
  • 起動中にAndroidが止まった場合、SiliconPlayはあきらめずに、より安全なグラフィックモードを順番に試します。
  • それでもAndroidが起動しない場合は、メッセージに本当の理由が表示され、Copy Diagnosticsで詳細をコピーして私に送れます。ログは~/Library/Logs/SiliconPlayにあります。

1.1.0の新機能：

自動アップデート

  • SiliconPlayは1日に1回ほど新しいバージョンを確認します。新しいバージョンが出ると一度だけお知らせします。Laterを選ぶと、次のバージョンが出るまでそのバージョンは表示されません。
  • SiliconPlay → Check for Updates…ですぐに確認できます。毎日の確認を止めたいときは、SettingsでCheck for updates automaticallyをオフにしてください。
  • Downloadを押すと、ディスクイメージを「ダウンロード」フォルダに保存して開きます。アプリはDeveloper IDで署名され、Appleの公証を受けています。

メインウインドウとインスタンス一覧

  • 起動するとメインウインドウ全体が開き、すべての操作ボタンが見えます。
  • クリックでインスタンスを選択できます。すでに選択中のものでも同じです。
  • 選択中のものも含め、どのインスタンスでも右クリックするとStart、Stop、Settings…、Rename…、Duplicate、Show in Finder、Deleteが表示されます。
  • インスタンスをダブルクリックすると設定が開きます。
  • mouse lookを含むゲームプリセットが、SiliconPlay自身のウインドウでのクリック、文字入力、スクロールを妨げなくなりました。

スクロールホイールでピンチズーム

  • Androidアプリでは、スクロールホイールでカーソル位置を中心にピンチズームするようになりました。タッチスクリーンを2本の指で操作するのと同じで、地図やゲームのカメラがスマホと同じようにズームします。リストをスクロールしたいときはShiftを押したまま回してください。
  • Settings → Scroll wheelでScroll the pageまたはCamera lookに変更できます。これらのモードではOptionを押しながらピンチズームします。

1.0からのアップデート方法

  1. SiliconPlay 1.1.2をダウンロードし、ディスクイメージを開きます。
  2. SiliconPlayを終了し、新しいアプリを「アプリケーション」フォルダにドラッグして古いものと置き換えます。インスタンスはアプリの外に保存されているので、そのまま残ります。
  3. キーボード操作が効かなくなったら、「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」でSiliconPlayをもう一度許可してください。アプリを置き換えると、macOSが改めて許可を求めることがあります。
  4. 今後は新しいバージョンがアプリ内で案内されます。

対応するMac

SiliconPlayはApple Silicon搭載Mac（M1〜M6）専用です。Intel Macsには対応していません。バージョン1.1.0はmacOS TahoeとmacOS 27 Golden Gateでテストしています。
