SiliconPlay 1.1.2 新功能

版本 1.1.2（建置 5）· Apple Silicon M1–M6 · 2026 年 11 月 20 日

SiliconPlay 1.1.2 是 Apple 晶片 Mac 上安卓模擬器的免費更新。現在它會自行保持最新，啟動後直接開啟完整的主視窗，全新的實例列表點下去的反應也和你預期的一樣。

下載 Mac 版 SiliconPlay 1.1.2

1.1.2：流暢捲動，以及根據你們的日誌所做的修正

1.1.2 版（建置 5）根據使用者寄來的日誌製作，並新增捲動與縮放控制。

  • 在 macOS Sequoia 及更早版本上，Android 啟動更可靠。當最新的 Android Emulator 在這些系統上無法正常啟動時，SiliconPlay 會改用放在旁邊、經過測試的模擬器版本。
  • 如果 Android 啟動時反覆出現圖形錯誤，SiliconPlay 會自動切換到更安全的圖形模式並通知你。
  • Android 只是停止執行時，不再誤報「連接埠使用中」。
  • 環形選單中新增滑鼠滾輪與觸控式軌跡板的自動、捏合和捲動模式。自動模式在 App 中捲動，在遊戲中捏合縮放。
  • 觸控式軌跡板捲動流暢，從 Android 啟動的那一刻起就跟著你的手指，放開後清單還會繼續滑動。
  • 捲動與捏合靈敏度：環形選單中的 Speed 扇區可在 0.25× 到 3× 之間調整，設定中兩者各有一個滑桿，並可用 Reset 回到 1×。
  • 停止實例更穩定：SiliconPlay 會先讓 Android 自行關機，再將其關閉。

1.1.1：Android 啟動更可靠

1.1.1 版（建置 4）是一個修正更新。在啟動過程中出現「could not start」而停住的 Mac 上，它應該能幫助 Android 正常啟動，尤其是 macOS Sequoia 及更早版本，或 Android Emulator 自動更新到新版本之後。

  • 啟動 Android 之前，SiliconPlay 會讀取 Android Emulator 的版本。在 macOS Sequoia 及更早版本上，如果模擬器比測試過的版本更新，就會以 OpenGL ES 圖形模式啟動。
  • 如果 Android 在啟動過程中停住，SiliconPlay 會依序嘗試更安全的圖形模式，而不是直接放棄。
  • 如果 Android 仍然無法啟動，提示會顯示真正的原因，Copy Diagnostics 會複製詳細資訊，方便你寄給我。記錄檔位於 ~/Library/Logs/SiliconPlay。

1.1.0 新增：

自動更新

  • SiliconPlay 大約每天檢查一次是否有新版本。有新版本時只會提醒一次。點 Later 會隱藏該版本，直到下一個版本推出。
  • SiliconPlay → Check for Updates… 會立即檢查。若不需要每天檢查，可在 Settings 關閉 Check for updates automatically。
  • Download 會把磁碟映像檔存到「下載項目」資料夾並開啟。App 以 Developer ID 簽署，並已通過 Apple 公證。

主視窗與實例列表

  • App 啟動後直接開啟完整的主視窗，所有控制按鈕一覽無遺。
  • 按一下即可選取實例，已選取的實例也一樣。
  • 在任何實例上按右鍵（包括已選取的），就會看到 Start、Stop、Settings…、Rename…、Duplicate、Show in Finder 和 Delete。
  • 按兩下實例即可開啟它的設定。
  • 含有 mouse look 的遊戲預設不再擋住 SiliconPlay 自身視窗中的點按、輸入和捲動。

用滑鼠滾輪雙指縮放

  • 在安卓 App 中，滑鼠滾輪現在會以游標位置為中心雙指縮放，就像在觸控螢幕上用兩根手指操作。地圖和遊戲鏡頭的縮放方式和手機上一樣。若要捲動列表，請按住 Shift。
  • 可在 Settings → Scroll wheel 改為 Scroll the page 或 Camera look。在這兩種模式下，按住 Option 即可縮放。

如何從 1.0 更新

  1. 下載 SiliconPlay 1.1.2 並打開磁碟映像檔。
  2. 結束 SiliconPlay，把新的 App 拖到「應用程式」資料夾並取代舊版。實例存放在 App 之外，所以都會保留。
  3. 如果鍵盤控制失靈，請打開「系統設定」→「隱私權與安全性」→「輔助使用」，重新允許 SiliconPlay。取代 App 後，macOS 可能會再次要求這項權限。
  4. 之後有新版本時，會直接在 App 內通知你。

支援哪些 Mac

SiliconPlay 僅支援搭載 Apple 晶片的 Mac（M1 至 M6），不相容於 Intel Macs。1.1.0 版已在 macOS Tahoe 和 macOS 27 Golden Gate 上測試。
