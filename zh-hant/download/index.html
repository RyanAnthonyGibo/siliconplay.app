SiliconPlay 是給 M1 到 M6 Apple 晶片 Mac 用的免費安卓模擬器。檔案是 SiliconPlay.dmg，版本 1.1.3。DMG 是 Mac 應用程式。安卓系統本身在第一次打開時下載。

下載 Mac 版 SiliconPlay

檔案到手之後

  1. 打開 DMG，把 SiliconPlay 拖進應用程式。
  2. 打開 SiliconPlay。第一次執行會接受 Android SDK 授權，並下載 Apple 晶片模擬器、platform-tools 和 Play arm64 映像，除非你已經有包含 emulator、adb 和 sdkmanager 的 SDK。
  3. Android 16 平板起來之後（1920×1080、320 dpi、橫向），登入 Google Play，或安裝一個 APK。

你需要什麼

  • 一台 Apple 晶片 Mac，M1 到 M6，包括 Pro、Max 和 Ultra。
  • 已在 macOS Tahoe 和 macOS 27 Golden Gate 上試過。其他版本可以試，然後告訴我發生了什麼。
  • 不相容 Intel Macs。

快速鍵，Cmd+I 排第一

  • Cmd+I 在安卓已經執行時安裝一個 APK。選單裡寫的是 Command-I。拖放是同一種安裝。
  • F12 或 Command-K 在打字和遊戲鍵之間切換。
  • F10 是對話框需要手指時的直接觸控。
  • Command-Shift-G 顯示或隱藏畫面上的按鈕。
  • Shift-Escape 放開卡住的虛擬手指。
  • Escape 離開全螢幕。全螢幕之外，畫面有焦點時它是安卓的返回。

如果因為缺少 JDK 而停住，macOS 顯示的是 /usr/bin/java 這個佔位程式。提示指向 brew install openjdk@17。裝上之後再跑一遍套件步驟。更長的說明在部落格，各工具的位置在 比較頁.
