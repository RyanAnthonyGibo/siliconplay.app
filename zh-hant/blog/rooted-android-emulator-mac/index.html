SiliconPlay · 部落格

在 Apple Silicon 的 Mac 上，一台可以選擇 root 的安卓環境

作者： Ryan Gibo · 2026年10月27日

若你只是想知道一支 APK 跑不跑得起來，把整套 IDE 打開會多出一堆手續。SiliconPlay 是放在一台真正的安卓平板前面的小型 Mac 軟體：ARM64、Android 16，而且只在 Apple Silicon 上。我是 Ryan，這支軟體是我從頭寫的。裡頭用的是官方的 Android Emulator。授權聲明有寫到那套模擬器，以及一起出現的 SDK 元件。

對象只有 Apple Silicon。M1 到 M5，以及同一條產品線裡更後面的晶片，Pro、Max、Ultra 都算在內。在 Apple Silicon 的 ARM 核心上原生執行，從 M1 到 M5 以及更新的晶片。到目前為止，我只在 macOS Tahoe 上試過。你若試了別的 macOS，把結果 寄給我。我寧願聽到實際狀況，也不想自己猜。

下載之後，你手上其實有什麼

你抓下來的檔案裡，並沒有把 Google 的模擬器或系統映像打包進去。第一次打開時，軟體會請你下載安卓再啟動。這個步驟會在這台 Mac 上同意 Android SDK 的授權，接著才抓 Google 的 command-line tools、Apple silicon 模擬器、platform-tools，還有 Play 的 arm64 系統映像，放到你指定的 SDK 資料夾。然後會建立一台橫向平板，名稱是 Android 16 Tablet，用自己的視窗打開。這台預設是 1920×1080、320 dpi、橫向、自動旋轉關掉，系統則是 Android 16 Play 映像。

那套映像就定位之後，Google Play 才會出現。它不是我塞在軟體裡的商店。請到安卓主畫面打開 Play Store 再登入。那組密碼，SiliconPlay 不會看到。如果你本來就有含 emulator、adb 和 sdkmanager 的 SDK，把軟體指到那個資料夾即可，不必再抓第二份。

若是因為 macOS 沒有 JDK 而停住，軟體會直接講。/usr/bin/java 在 macOS 上只是一支 stub。軟體裡的訊息指向 brew install openjdk@17，裝好之後把那個元件步驟再跑一次。

不必守在 IDE 裡也能裝 APK

要先把執行個體跑起來，才能安裝。然後把 .apk 拖進去，或按 Command-I 匯入 APK 並安裝。這個版本不會安裝 Split APK 和 XAPK 壓縮檔，所以只有那些格式的套件進不去。若你只是要確認「我這次的建置裝上了沒、打得開嗎」，這樣就夠了。你點應用程式的時候，不必讓 Android Studio 一直開著。

用 adb 裝也可以。那樣複製過去的檔案會進 /sdcard/SiliconPlay。這些映像不會把宿主機的資料夾掛成一顆即時磁碟，所以別等共享資料夾自己出現在安卓裡。

Pro Mode 在你打開之前是關的。它放在工具列、View 選單和 Settings。關著的時候，主視窗就是 Start、Stop 和 Create New Instance。打開之後，主視窗還會多出硬體、鍵位和診斷。

root 是選項，而且一開始是關的

root 可開可關，預設是關。一般的 Play 平板就讓它關著。只有要 adb root 時才打開。

做了 root 的平板用的是 Google APIs 映像檔，因為 Play 映像檔會拒絕 adb root。那台平板沒有 Play Store。APIs 映像檔會在你第一次建立這種平板時才下載。若你同時要 Play 登入和 root，那是兩台平板，不是 Play 映像檔上可以撥過去的開關。

沒有核心擴充，也沒有事後要移除的背景服務。用完就把軟體刪掉。SDK 的檔案留在你選的那個 SDK 資料夾。SiliconPlay 自己的檔案在 ~/Library/Application Support/SiliconPlay。

你在測的應用程式若本身沒有按鍵

預設就是直接觸控，自己做的介面通常這樣就對了。若你是在點一款遊戲，畫面上的鍵位和快速鍵清單是另外一半。

問題

一定要 root 嗎？

不用。root 是選項，預設關掉。root 用的是 Google APIs 映像檔。Play 映像檔會拒絕 adb root，那台做了 root 的平板也不含 Play Store。

APK 要怎麼裝？

先把執行個體跑起來，再把 APK 拖進去，或按 Command-I 匯入。adb 也可以裝。這個版本不安裝 Split APK 和 XAPK 壓縮檔。經由 adb 複製的檔案會到 /sdcard/SiliconPlay。

Android Studio 得開著嗎？

不用。不必讓整套 IDE 擋在前面，也能裝好 APK 再試。軟體會去抓官方模擬器和 Play 的 arm64 映像檔，或沿用你已經有的 SDK。

哪些 Mac、哪個 macOS？

只有 Apple Silicon：M1、M2、M3、M4、M5 和更新的晶片，含 Pro、Max、Ultra。在 Apple Silicon 上原生執行。到目前為止只在 macOS Tahoe 上試過。
