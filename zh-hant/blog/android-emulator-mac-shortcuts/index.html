Mac 上這套安卓環境的快速鍵：SiliconPlay 實際寫出來的那些

作者： Ryan Gibo · 2026年10月27日

下面是 SiliconPlay 在 Mac 上的鍵盤快速鍵，我是從軟體本身抄出來的（version 1.0.0, build 2）。Command-I 則是我另外核對過的。別的模擬器上的快速鍵，我沒有拿來填空；沒查到的組合，我也沒有自己編。下面沒寫的，就是我核對不了的，所以不放進來。

SiliconPlay 只給 Apple Silicon：M1、M2、M3、M4、M5，以及同一條產品線裡更後面的晶片。在 Apple Silicon 的 ARM 核心上原生執行，從 M1 到 M5 以及更新的晶片。我是在 macOS Tahoe 上試的。別的 macOS 若行為不一樣，請 跟我說。

按下去之後，鍵會去哪

先點安卓畫面，鍵盤才進到鍵位。帶 Command 鍵的選單快速鍵留在 macOS，不會被打進遊戲裡。文字欄位一旦有焦點，工具列會改成 Typing，鍵盤就以文字的方式進入安卓。

同一個版本的 Shortcuts 清單還列了這些動作的名字，可是我沒有可以跟著寫的按鍵組合：啟動或停止選取的執行個體、切換全螢幕、離開全螢幕預覽、存一張螢幕擷圖、開始或停止螢幕錄影、編輯鍵位、在直接觸控和已對應的按鍵之間切換、顯示或隱藏安卓按鈕，以及在正在跑的執行個體之間同步輸入。名字旁邊的鍵是選單畫上去的。這個版本沒有把它存成另一條讀得到的字串，所以我不會編一套。請打開軟體裡的 Shortcuts and limits，看你這台機器上的組合。

還沒改過的話，預設鍵位長這樣

鍵位還沒載入時，Game keys 幫不上忙。通用的那份叫做 MMORPG (WASD)，而且沒有綁死某一款遊戲。先套用，再把按鈕挪開。完整的編輯步驟在 Mac 上的按鍵對應。那份檔案裡接好的是：

你一旦接受某款遊戲自己的配置，它就會換掉這一組。Minecraft 的配置就是例子：break 用 left click，inventory 用 E，而不是 J 和 M。建議你還沒接受之前，直接觸控會維持開啟，這些 Game keys 也不會被載入。

問題

打字和遊戲按鍵要用什麼換？

F12 或 Command-K。Game keys 走鍵位。Typing 把鍵盤送進安卓。文字欄位會自己改成 Typing。

Escape 到底做什麼？

它會離開全螢幕。視窗不是全螢幕時，只要畫面有焦點，Escape 就是 Android Back。Shift-Escape 會放開每一根虛擬手指。正在改綁時，Escape 取消這次按鍵擷取。

這些就是軟體裡全部的快速鍵嗎？

Command-I 會匯入 APK，並安裝進安卓。表格剩下的，是 1.0.0 說明文字寫出來的全部分組，再加上預設鍵位。Shortcuts 清單裡還有幾個動作只有名字，這個版本沒有讀得到的按鍵字串。那些組合請打開軟體看。

哪些 Mac 可以用？

Apple Silicon 的 Mac：M1、M2、M3、M4、M5，包括 Pro、Max、Ultra。
