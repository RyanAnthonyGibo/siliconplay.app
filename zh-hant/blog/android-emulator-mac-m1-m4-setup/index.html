Mac M1、M4 安卓模擬器：一步步安裝教學

作者： Ryan Gibo · 2026年10月28日

搜尋「Mac M1 安卓模擬器」或「Mac M4 Android 模擬器」，很多結果寫於 Apple Silicon 之前。這裡是簡短、最新的版本：用我為 Apple Silicon 開發的 SiliconPlay，在 M 系列晶片的 Mac 上執行 Android 遊戲和 App。

你安裝的是什麼

SiliconPlay 底層執行的是 Google 官方的 Android Emulator，原生跑在 Mac 的 ARM 核心上。外面這層 Mac App，也就是介面和操控對應，是我從零寫的。它只為 Apple Silicon 打造，支援 M1 到 M5，我在 macOS Tahoe 上測試過。

你需要什麼

  • 一台搭載 M1、M2、M3、M4 或 M5 晶片的 Mac（包含 Pro、Max 和 Ultra）。
  • macOS Tahoe。這是我測試過的版本。
  • 一個 Google 帳號，如果你想從 Google Play 安裝。

安裝步驟

  1. 下載 SiliconPlay.dmg。
  2. 打開 DMG，把 SiliconPlay 拖到「應用程式」。
  3. 打開 SiliconPlay，啟動 Android。
  4. 登入 Google Play，安裝你的遊戲和 App。要安裝 APK 檔，按 Command-I。
  5. 點一下 Android 畫面。預設是直接觸控。想用鍵盤玩，就接受 SiliconPlay 為你的遊戲推薦的預設，或套用 MMORPG (WASD) 再移動按鈕。

下載 Mac 版 SiliconPlay

先記住這幾個快捷鍵

  • Command-I：匯入 APK 並安裝到 Android。
  • F12 或 Command-K：在 Typing 和 Game keys 之間切換。
  • Command-Shift-G：顯示或隱藏螢幕上的遊戲按鈕。
  • Escape：離開全螢幕。不在全螢幕時，它是 Android 的返回鍵。
  • Shift-Escape：放開所有虛擬手指。

M1 和 M4 有什麼不同？

從 M1 到 M5，每顆晶片上的 App 都一樣。我沒有公布各晶片的跑分，所以不會給你 M1 或 M4 的數字。新晶片餘裕更大，在重度 3D 遊戲裡差別最明顯。如果遊戲卡頓，先調低遊戲裡的畫質設定。沒有 ARM 版本的 App 在哪顆晶片上都跑不了，不過現在大多數 App 都有 ARM 版本。

問題

Mac M1 能用嗎？

可以。M1、M2、M3、M4 和 M5 都行，包含 Pro、Max 和 Ultra。

需要哪個版本的 macOS？

我在 macOS Tahoe 上測試過 SiliconPlay。如果其他版本表現不同，請告訴我。

這是 Google 的模擬器嗎？

底層是：Google 官方的 Android Emulator。介面和操控對應是 SiliconPlay 自己的，從零寫成。

需要 root 嗎？

不需要。root 是選用的，預設關閉，留給需要它的開發者。
