在 Mac 上為安卓遊戲做按鍵對應：畫面上的按鈕，還有各遊戲自己的配置

作者： Ryan Gibo · 2026年10月27日

安卓遊戲多半是為手指設計的。Mac 上本來就有鍵盤和滑鼠，有的人也有手把，可是一直在觸控板上點，玩久了很累。我做的 SiliconPlay 會在遊戲畫面放上按鈕，讓實體按鍵去按那些位置。若你在找 Mac安卓模擬器的按鍵對應，指的就是這件事：按鍵或搖桿會變成你選好的那一下觸控。

這套軟體只在 Apple Silicon 上跑，M1 到 M5，以及同一條產品線裡更後面的晶片。在 Apple Silicon 的 ARM 核心上原生執行，從 M1 到 M5 以及更新的晶片。我自己是在 macOS Tahoe 上試的。你若是別的 macOS 版本，發生了什麼事請 寫信給我。

還沒要按鍵的時候，維持直接觸控

打開之後就是直接觸控。指標扮演手指，選單、商店，或是沒有鍵位的應用程式，這樣最順。若前面是一款軟體認得的遊戲，它可以拿出社群配置。那份配置會先關著，等你接受才算數。不會因為應用程式一開，鍵位就自己載進來。

先點安卓的畫面，鍵盤才會進到鍵位。文字欄位有焦點時，工具列會寫著 Typing，這時候按鍵是打進安卓，不是去按畫面上的按鈕。F12 或 Command-K 用來在 Typing 和 Game keys 之間換。帶 Command 鍵的選單快速鍵仍然屬於 macOS。

就算焦點在 SiliconPlay 的視窗上，按鍵也照樣有用。軟體第一次跟著模擬器自己的視窗走時，macOS 會問你要不要開 Accessibility。還沒允許之前，讓 SiliconPlay 的視窗保持焦點就好，按鍵還是進得去。

預設的配置叫做 MMORPG (WASD)

軟體裡附的通用配置，名稱是 MMORPG (WASD)。它沒有綁定某個 package，所以不會自動跳出來建議你用。你可以套到任何遊戲，再把沒對準的地方修一修。搖桿會先碰到自己那顆按鈕的正中央，方向鍵按住時往外滑；放手就滑回中央。

這份配置上的註記就是叫你進編輯器再調。那些座標先當成起點就好。它們是遊戲畫面的比例，範圍從 0 到 1，原點在左上角，視窗縮放時會一起跟著變。

把按鈕拖到真的蓋在遊戲上

按 Edit layout 會打開鍵位編輯器。拖按鈕就能搬家。在按鈕上點一下，可以改綁鍵盤或滑鼠按鍵。拖 gold dot 則是改大小。還能加 WASD 搖桿、鏡頭拖曳、點一下、長按、滑動或重複。Done 會存檔。Cancel 會把設定檔還原成你打開編輯器時的樣子。若正在等你按鍵，Escape 會取消這次擷取。

模擬器另外那扇視窗上，有一顆玻璃泡泡跟著走。拖泡泡可以移動它。點下去則會看到疊加層、不透明度、大小、編輯和重設。這個位置會記在設定檔裡。Command-Shift-G 用來切換疊加層。畫面上的空白處，點下去仍然是點到遊戲。

F10 會改成直接觸控。選單要的是真的手指，不是已經對好的按鈕時，這樣比較單純。虛擬手指若卡住沒起來，Shift-Escape 會把每一根都放開。

手把按的是同一組按鈕

一顆畫面上的按鈕可以同時聽一種以上的輸入。預設配置裡，skill 1 同時是數字鍵 1 和 gamepad X，跳躍則是 Space 和 gamepad B。重新綁定時，face buttons、shoulders、triggers、D-pad、menu 和 options 也能接上。手把不是另一套操作。它按下的，就是鍵盤正在按的那些畫面按鈕。

每款遊戲可以有自己的配置

有些應用程式自帶配置，靠 package 對上。那款遊戲在前面時，SiliconPlay 會拿出來，然後停下來等你。先接受，再把沒蓋到圖的按鈕拖過去。這些檔案上的說法是社群配置。

Minecraft 很適合拿來對照，因為它不是那套通用配置。它用 WASD 移動，左鍵用來破壞，右鍵用來使用，Space 跳躍，E 開物品欄，1 到 3 是快捷欄，滑鼠右鍵用來轉視角。按鈕散落在不同角落的遊戲，要的是這種調整，而不是沿著底邊排一列 MMORPG 按鈕。

同一個版本裡，我也放了 Genshin Impact、Roblox、Call of Duty Mobile 和 Clash of Clans 的配置。我不會假裝一份配置就能套完全部。先接受建議，玩一下子，再把按鈕挪到位。

若你在網路上看到別人的鍵位

比較能信的，還是軟體裡的那一份。別人貼出來的配置，必須是 SiliconPlay 的鍵位檔：format id 為 stardroid.keymap 的 JSON。不符合這個格式的 JSON 會被拒絕。分享檔裡的位置是照別人的螢幕畫的，所以請打開編輯器，把按鈕對到你自己的畫面上。

Pro Mode 放在工具列、View 選單和 Settings。打開之後，主視窗會多出硬體、鍵位和診斷。你沒開，它就維持關閉。模擬器視窗上的泡泡仍然有編輯、疊加層、不透明度、大小和重設。

問題

哪些 Mac 跑得動 SiliconPlay？

跑不動。只支援 Apple Silicon：M1、M2、M3、M4、M5，以及同一條產品線裡更後面的晶片。

一定要開按鍵對應嗎？

不用。一開始就是直接觸控。軟體建議的配置會先關著，等你按接受才會載入。

手把可以用嗎？

可以。手把按下去的是跟鍵盤同一批畫面上的按鈕。MMORPG 那套已經幫幾個技能和跳躍接好了。

我的遊戲要去哪裡找配置？

用軟體提出來的那份，或自己套上 MMORPG (WASD) 再改。從別處拿到的檔案，必須是合法的 stardroid.keymap JSON。
