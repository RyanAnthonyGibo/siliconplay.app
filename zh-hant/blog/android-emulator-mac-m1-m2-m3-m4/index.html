M1–M6 Mac 的安卓模擬器

作者： Ryan Gibo · 2026年10月26日

如果你的 Mac 是 Apple 晶片，你手上已經有一台很快的 ARM 電腦，而 Android 也是 ARM 系統。SiliconPlay 把這兩件事接到一起。它讓 Android 16 直接跑在 Mac 的核心上，用的是 Apple 的 Hypervisor，畫面由 Metal 繪製。在 Mac 的 ARM 核心上原生執行。免費，玩遊戲和試 App 都可以。

哪些 Mac 能用？

M1 到 M6 的所有 Apple 晶片 Mac，包括 Pro、Max、Ultra。SiliconPlay 底層用的是 Google 官方的 Android Emulator，在 Mac 的 ARM 核心上原生執行。我在 macOS Tahoe 和 macOS 27 Golden Gate 上測試過。如果你在其他 macOS 版本上試了，請告訴我效果。

用來玩遊戲

鍵盤和手把的覆蓋層可以 WASD 移動、J 攻擊、1-6 放技能，也可以自己改鍵。在 M3 Max 的 MacBook Pro 上，我測過重負載 3D 遊戲最高 60 幀，解析度最高 2560×1440，按鍵到遊戲 7 到 43 毫秒。結果會隨遊戲、Mac 和設定改變。

開發也能用

不用把整個 IDE 開起來，就能在真正的 ARM64 Android 上試 APK。root 是可選的，預設關掉。平時玩遊戲，系統還是原樣。只有除錯需要系統權限時才打開。

沒有附帶的東西

沒有核心擴充，沒有背景服務，也沒有塞進來的軟體。刪掉 App 就沒了。

怎麼裝

  1. 下載 SiliconPlay.dmg。
  2. 把 SiliconPlay 拖進「應用程式」。
  3. 打開，登入 Google Play，再裝你的遊戲或 App。

M1 到 M6 是同一個應用程式

M1、M2、M3、M4、M5 和 M6 不是分開下載的。SiliconPlay 是一個 Mac 應用程式。Pro、Max 和 Ultra 是核心更多的同一類晶片，不是另一個產品。第一次執行在每顆晶片上做同樣的事：接受 Android SDK 授權，然後把 command-line tools、Apple 晶片模擬器、platform-tools 和 Play arm64 映像放到你選的資料夾。

平板名叫 Android 16 Tablet，橫向，1920×1080，320 dpi，自動旋轉關閉。2560×1440 不是這塊平板的尺寸。它來自唯一發表過的測量，一台 M3 Max 的 MacBook Pro：高負載 3D 裡最高 60 fps，渲染最高 2560×1440，按鍵到遊戲 7–43 毫秒。我沒有為 M1、M2、M4、M5 或 M6 發表過同一組測量。

如果缺 JDK，macOS 顯示的是 /usr/bin/java 這個佔位程式。提示指向 brew install openjdk@17。晶片不改變這句話。沒有 ARM64 程式庫的套件在名單上的任何晶片上都不會跑。這個版本不安裝拆分 APK，也不安裝 XAPK。

快速鍵，Cmd+I 排第一

  • Cmd+I 在實例已經執行時安裝一個 APK。選單裡寫的是 Command-I。拖放是同一種安裝。
  • F12 或 Command-K 在打字和遊戲鍵之間切換。
  • F10 是對話框需要手指時的直接觸控。
  • Command-Shift-G 顯示或隱藏畫面上的按鈕。
  • Shift-Escape 放開卡住的虛擬手指。
  • Escape 離開全螢幕。全螢幕之外，畫面有焦點時它是安卓的返回。

晶片名字說明不了的事

遊戲卡的話，先降低它自己的畫質。不要因為名字是 M1 或 M4，就斷定這台 Mac 不合適。我在 macOS Tahoe 和 macOS 27 Golden Gate 上試過。別的版本可以試，然後把晶片和版本告訴我。不相容 Intel Macs。Vulkan 由 Metal 繪製，著色器使用 safe math，好讓樹葉正確。這不是按晶片分開的模式。
