SiliconPlay: emulator Android gratis untuk Mac (M1 sampai M5)

SiliconPlay adalah emulator Android gratis untuk Mac Apple Silicon (M1, M2, M3, M4, M5, dan yang lebih baru). Cocok untuk main game dan untuk pengembangan: Android berjalan di inti ARM Mac lewat Hypervisor Apple, dan Metal yang menggambar. Berjalan secara native di inti ARM Mac.

Unduh SiliconPlay untuk Mac

Isinya

  • Android 16 ARM64 asli di Apple Silicon.
  • Vulkan digambar Metal, shader dalam mode aman supaya dedaunan tampil benar.
  • Lapisan keyboard dan gamepad: WASD untuk bergerak, J untuk serang, 1-6 untuk skill.
  • Tanpa ekstensi kernel, tanpa layanan latar, tanpa perangkat lunak numpang.

Diukur di MacBook Pro dengan M3 Max

  • Sampai 60 fps di game 3D yang berat.
  • Resolusi render sampai 2560×1440.
  • 7 sampai 43 ms dari tombol ke game.

Perlu Mac dengan Apple Silicon (M1 atau lebih baru) dan macOS 14 atau lebih baru. Hasilnya tergantung game, Mac, dan pengaturan.

Gratis. Mendukung proyek ini bersifat pilihan.

SiliconPlay gratis untuk main game dan untuk menguji aplikasi. Mau mendukung proyek atau tidak, itu keputusanmu.
