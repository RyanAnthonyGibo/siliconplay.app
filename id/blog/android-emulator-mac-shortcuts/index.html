Pintasan emulator Android di Mac: daftar keyboard SiliconPlay

Oleh Ryan Gibo · 27 Oktober 2026

Ini daftar pintasan keyboard untuk SiliconPlay di Mac, diambil dari aplikasi itu sendiri (version 1.0.0, build 2) plus Command-I, yang saya pastikan terpisah. Saya tidak mengisi celah dengan shortcut dari emulator lain, dan saya tidak mengarang kombinasi yang tidak ada. Kalau sebuah kombinasi tidak tertulis di bawah, saya tidak bisa memverifikasinya, jadi kombinasi itu tidak saya masukkan.

SiliconPlay hanya untuk Apple Silicon: M1, M2, M3, M4, M5, dan chip yang lebih baru di lini itu. Berjalan secara native di Apple Silicon, dari M1 sampai M5 dan yang lebih baru. Saya sudah mengujinya di macOS Tahoe. Kalau versi macOS lain berperilaku berbeda, kabari saya.

Ke mana tuts itu pergi

Klik gambar Android supaya keyboard masuk ke keymap. Shortcut menu yang memakai tombol Command tetap di macOS. Kombinasi itu tidak diketik ke dalam game. Bidang teks yang fokus mengubah toolbar menjadi Typing, lalu keyboard masuk ke Android sebagai teks.

Keymap bawaan, kalau Anda belum menyuntingnya

Game keys belum berguna sampai ada keymap yang aktif. Preset umumnya adalah MMORPG (WASD). Preset ini tidak terikat pada satu game. Anda memasangnya, lalu memindahkan tombol. Langkah penyuntingan lengkap ada di pemetaan keyboard di Mac. Ikatan pada berkas itu adalah:

Preset per game menggantikan ikatan ini setelah Anda menerimanya. Preset Minecraft, misalnya, memakai left click untuk break dan E untuk inventory, bukan J dan M. Sampai Anda menerima saran, sentuhan langsung tetap menyala dan Game keys ini tidak dimuat.

Pertanyaan

Apa yang beralih antara mengetik dan tombol game?

F12 atau Command-K. Game keys memakai keymap. Typing mengirim keyboard ke Android. Bidang teks beralih ke Typing dengan sendirinya.

Apa yang dilakukan Escape?

Escape keluar dari layar penuh. Saat jendela tidak sedang layar penuh, Escape adalah Android Back selama tampilan fokus. Shift-Escape melepaskan setiap jari virtual. Saat mengikat ulang, Escape membatalkan penangkapan.

Apakah ini semua shortcut di aplikasi?

Command-I mengimpor APK dan memasangnya ke Android. Sisa tabel adalah setiap kombinasi yang ditulis teks bantuan 1.0.0, plus keymap bawaan. Beberapa tindakan lain dinamai di daftar Shortcuts tanpa string tuts yang terbaca di build itu. Periksa aplikasinya untuk kombinasi tersebut.

Di Mac mana ini berjalan?

Mac dengan Apple Silicon: M1, M2, M3, M4, dan M5, termasuk Pro, Max, dan Ultra.
