SiliconPlay is a free Android emulator for Macs with Apple silicon, from M1 through M6. The file is SiliconPlay.dmg, version 1.1.3. The DMG is the Mac app. Android itself downloads the first time you open it.

Download SiliconPlay for Mac

After the file arrives

  1. Open the DMG and drag SiliconPlay to Applications.
  2. Open SiliconPlay. The first run accepts the Android SDK license and downloads the Apple silicon emulator, platform-tools, and the Play arm64 image, unless you already have an SDK with emulator, adb, and sdkmanager.
  3. When the Android 16 tablet is up (1920×1080, 320 dpi, landscape), sign in to Google Play or install one APK.

What you need

  • A Mac with Apple silicon, M1 through M6, including Pro, Max, and Ultra.
  • Tested on macOS Tahoe and macOS 27 Golden Gate. If you are on another version, try it and tell me what happened.
  • Not compatible with Intel Macs.

Shortcuts, Cmd+I first

  • Cmd+I installs one APK once Android is running. The menu shows Command-I. Drag and drop does the same install.
  • F12 or Command-K switches Typing and game keys.
  • F10 is direct touch when a dialog wants a finger.
  • Command-Shift-G shows or hides the on-screen buttons.
  • Shift-Escape releases a stuck virtual finger.
  • Escape leaves fullscreen. Outside fullscreen it is Android Back while the display is focused.

If setup stops on a missing JDK, macOS is showing the stub at /usr/bin/java. The message points at brew install openjdk@17. Install that and run the package step again. A longer setup is on the blog, and the product lineup is on the comparison.
