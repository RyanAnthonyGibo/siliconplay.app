มีอะไรใหม่ใน SiliconPlay 1.1.3

เวอร์ชัน 1.1.3 (บิลด์ 6) · Apple Silicon M1–M6 · 27 พฤศจิกายน 2026

SiliconPlay 1.1.3 เป็นอัปเดตฟรีของ Android emulator สำหรับ Mac ชิป Apple Silicon ปุ่มคีย์บอร์ดและเมาส์ที่แมปไว้ใช้ได้ขณะเล่น คลิกสั้นบนเมนูวงกลมติด และการหยุดอินสแตนซ์จะเก็บแอปกับข้อมูลที่ติดตั้งไว้

ดาวน์โหลด SiliconPlay 1.1.3 สำหรับ Mac

1.1.3: การควบคุม ข้อมูลที่บันทึก และกราฟิก 2D

เวอร์ชัน 1.1.3 (บิลด์ 6) แก้การป้อนข้อมูลขณะเกมเปิดอยู่ บันทึกสแนปช็อตที่สะอาดตอนหยุด และเก็บปัญหาภาพสองอย่างในเกม 2D

  • ปุ่มคีย์บอร์ดและเมาส์ที่แมปไว้ส่งถึงเกมทุกครั้งที่หน้าต่างอีมูเลเตอร์อยู่ด้านหน้า ถ้า macOS หยุดการจับอินพุตชั่วคราว SiliconPlay จะเปิดกลับให้ ผูก Shift, Control และ Option ได้ ทางลัด Command ใน SiliconPlay ยังเหมือนเดิม
  • คลิกสั้นบนชิ้นของเมนูวงกลมติดตั้งแต่กดจนปล่อย และพื้นที่ที่โดนตรงกับชิ้นนั้น
  • การหยุดอินสแตนซ์จากเมนูจะซิงก์เกสต์แล้วบันทึกลงสแนปช็อตของอินสแตนซ์นั้น แอปที่ติดตั้งและข้อมูลยังอยู่ ไม่ย้อนกลับไปสแนปช็อตที่เก่ากว่าอีก
  • เกม 2D บน OpenGL ES ไม่เลื่อนแผนที่และไม่ทิ้งแถบเก่าที่ขอบล่างอีก SiliconPlay เลิกบังคับ MESA_KK_DISABLE_WORKAROUNDS=all และแท็บเล็ตที่มีอยู่จะทิ้งค่านี้เอง คอนฟิกแท็บเล็ตใช้ pixel_tablet กับ hw.displayCutout=none วงกลมกล้องสีดำจึงหายไป
  • พร้อมสำหรับ Android Emulator 37.3.10 บน macOS 26 ขึ้นไป การย้ายจาก 37.2 ไป 37.3 จะ cold boot หนึ่งครั้ง และ KosmicKrisp จะถอยอย่างปลอดภัยถ้าจำเป็น บนอีมูเลเตอร์ 37.2.12 App Nap ปิดระหว่างเซสชัน อีมูเลเตอร์ 36.4.9 ขึ้นไปถอยไปที่ -gpu software ได้ บน macOS 27 ขึ้นไป ชั้นดีบักของ Metal ปิดไว้ macOS 15 อยู่ที่อีมูเลเตอร์ 37.2.12

1.1.2: เลื่อนลื่นไหลและแก้ไขจากล็อกของคุณ

เวอร์ชัน 1.1.2 (บิลด์ 5) สร้างจากล็อกที่ผู้ใช้ส่งมา และเพิ่มการควบคุมใหม่สำหรับการเลื่อนและการซูม

  • Android เริ่มทำงานได้เสถียรขึ้นบน macOS Sequoia และรุ่นก่อนหน้า เมื่อ Android Emulator รุ่นใหม่ล่าสุดเริ่มทำงานได้ไม่ดี SiliconPlay จะใช้อีมูเลเตอร์รุ่นที่ทดสอบแล้วที่ติดตั้งไว้ข้างกัน
  • หากเกิดข้อผิดพลาดด้านกราฟิกซ้ำๆ ระหว่างที่ Android เริ่มทำงาน SiliconPlay จะสลับไปใช้โหมดกราฟิกที่ปลอดภัยกว่าเองและแจ้งให้คุณทราบ
  • ไม่มีข้อผิดพลาด “พอร์ตถูกใช้งานอยู่” ที่ผิดพลาดอีกแล้ว เมื่อ Android แค่หยุดทำงาน
  • โหมดใหม่ อัตโนมัติ บีบ และ เลื่อน สำหรับล้อเมาส์และแทร็คแพดในเมนูวงกลม อัตโนมัติ จะเลื่อนในแอปและบีบซูมในเกม
  • การเลื่อนด้วยแทร็คแพดลื่นไหลและตามนิ้วของคุณตั้งแต่ Android เริ่มทำงาน และรายการจะไหลต่อเมื่อคุณปล่อยนิ้ว
  • ความไวการเลื่อนและการบีบ: ส่วน Speed ในเมนูวงกลมปรับได้ตั้งแต่ 0.25× ถึง 3× และในการตั้งค่ามีแถบเลื่อนสำหรับแต่ละอย่าง พร้อม Reset เพื่อกลับไปที่ 1×
  • การหยุดอินสแตนซ์เสถียรขึ้น: SiliconPlay ปล่อยให้ Android ปิดตัวเองก่อนจะปิดมัน

1.1.1: เปิด Android ได้เสถียรขึ้น

เวอร์ชัน 1.1.1 (บิลด์ 4) เป็นอัปเดตแก้ไขปัญหา น่าจะช่วยให้ Android เปิดได้บน Mac ที่เคยค้างตอนบูตพร้อมข้อความ “could not start” โดยเฉพาะบน macOS Sequoia และเก่ากว่า หรือหลังจาก Android Emulator อัปเดตตัวเองเป็นเวอร์ชันใหม่

  • ก่อนเปิด Android แอป SiliconPlay จะอ่านเวอร์ชันของ Android Emulator บน macOS Sequoia และเก่ากว่า ถ้า emulator ใหม่กว่าเวอร์ชันที่ทดสอบ จะเริ่มในโหมดกราฟิก OpenGL ES
  • ถ้า Android หยุดระหว่างบูต SiliconPlay จะลองโหมดกราฟิกที่ปลอดภัยกว่าทีละโหมดแทนที่จะยอมแพ้
  • ถ้า Android ยังเปิดไม่ได้ ข้อความจะบอกสาเหตุจริง และ Copy Diagnostics จะคัดลอกรายละเอียดให้คุณส่งมาให้ผม ไฟล์ล็อกอยู่ที่ ~/Library/Logs/SiliconPlay

สิ่งใหม่ใน 1.1.0:

อัปเดตอัตโนมัติ

  • SiliconPlay จะตรวจหาเวอร์ชันใหม่ประมาณวันละครั้ง เมื่อมีเวอร์ชันใหม่จะแจ้งเพียงครั้งเดียว ปุ่ม Later จะซ่อนเวอร์ชันนั้นไว้จนกว่าจะมีเวอร์ชันถัดไป
  • SiliconPlay → Check for Updates… ตรวจทันที หากไม่ต้องการให้ตรวจทุกวัน ให้ปิด Check for updates automatically ใน Settings
  • Download จะบันทึกไฟล์ disk image ไว้ในโฟลเดอร์ Downloads แล้วเปิดให้ แอปนี้เซ็นด้วย Developer ID และผ่านการ notarize จาก Apple

หน้าต่างหลักและรายการอินสแตนซ์

  • แอปเปิดมาที่หน้าต่างหลักแบบเต็มทันที เห็นปุ่มควบคุมครบทุกปุ่ม
  • คลิกครั้งเดียวก็เลือกอินสแตนซ์ได้ รวมถึงอินสแตนซ์ที่เลือกอยู่แล้ว
  • คลิกขวาที่อินสแตนซ์ใดก็ได้ รวมถึงอันที่เลือกอยู่ เพื่อดู Start, Stop, Settings…, Rename…, Duplicate, Show in Finder และ Delete
  • ดับเบิลคลิกที่อินสแตนซ์เพื่อเปิดการตั้งค่า
  • พรีเซ็ตเกมที่มี mouse look จะไม่บล็อกการคลิก การพิมพ์ หรือการเลื่อนในหน้าต่างของ SiliconPlay อีกต่อไป

ซูมแบบบีบนิ้วด้วยล้อเมาส์

  • ในแอป Android ล้อเมาส์จะซูมแบบบีบนิ้วตรงตำแหน่งเคอร์เซอร์ เหมือนใช้สองนิ้วบนหน้าจอสัมผัส แผนที่และกล้องในเกมจึงซูมได้เหมือนบนมือถือ กด Shift ค้างไว้หากต้องการเลื่อนรายการ
  • เปลี่ยนได้ที่ Settings → Scroll wheel: Scroll the page หรือ Camera look ในโหมดเหล่านี้ให้กด Option ค้างไว้เพื่อซูม

วิธีอัปเดตจากเวอร์ชัน 1.0

  1. ดาวน์โหลด SiliconPlay 1.1.3 แล้วเปิดไฟล์ disk image
  2. ปิด SiliconPlay ลากแอปใหม่ไปไว้ใน Applications แล้วแทนที่แอปเดิม อินสแตนซ์ของคุณเก็บไว้นอกแอป จึงยังอยู่ครบ
  3. หากการควบคุมด้วยคีย์บอร์ดใช้ไม่ได้ ให้เปิด การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การช่วยการเข้าถึง แล้วอนุญาต SiliconPlay อีกครั้ง macOS อาจขอสิทธิ์นี้ใหม่หลังจากแทนที่แอป
  4. ต่อจากนี้ เวอร์ชันใหม่จะแจ้งให้คุณทราบภายในแอปเลย

ใช้กับ Mac รุ่นไหนได้

SiliconPlay ใช้ได้เฉพาะ Mac ชิป Apple Silicon ตั้งแต่ M1 ถึง M6 ไม่รองรับ Intel Macs เวอร์ชัน 1.1.0 ทดสอบแล้วบน macOS Tahoe และ macOS 27 Golden Gate
