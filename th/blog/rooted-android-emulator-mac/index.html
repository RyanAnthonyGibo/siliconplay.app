อีมูเลเตอร์ Android ที่รูทได้ สำหรับนักพัฒนาบน Mac Apple Silicon

โดย Ryan Gibo · 27 ตุลาคม 2026

ถ้าคุณแค่อยากรู้ว่า APK รันได้หรือไม่ การเปิด IDE ทั้งชุดเสียเวลามาก SiliconPlay เป็นแอป Mac ตัวเล็กที่อยู่หน้าแท็บเล็ต Android จริง: ARM64, Android 16, บน Apple Silicon ผมชื่อ Ryan และผมสร้างแอปนี้ขึ้นมาเองตั้งแต่ต้น ข้างในใช้ Android Emulator ตัวทางการ ประกาศสัญญาอนุญาตระบุชื่ออีมูเลเตอร์นั้นและชิ้นส่วน SDK ที่มาด้วย

ใช้ได้เฉพาะ Apple Silicon ตั้งแต่ M1 ถึง M5 และชิปรุ่นใหม่กว่าในสายเดียวกัน รวม Pro, Max และ Ultra รันบน Apple Silicon รวม M5 และชิปที่ตามมา ตอนนี้ผมทดสอบแค่บน macOS Tahoe ถ้าคุณลอง macOS รุ่นอื่น เล่าให้ผมฟังว่าเป็นอย่างไร ผมอยากได้เรื่องจริงมากกว่าการเดา

สิ่งที่คุณได้จริงๆ

ไฟล์ที่ดาวน์โหลดมาไม่ได้บรรจุอีมูเลเตอร์ของ Google และไม่มี system image อยู่ข้างใน ครั้งแรกรัน แอปจะขอให้ดาวน์โหลด Android แล้วเริ่มทำงาน ขั้นตอนนั้นยอมรับสัญญาอนุญาต Android SDK บน Mac เครื่องนี้ จากนั้นดาวน์โหลด command-line tools ของ Google, อีมูเลเตอร์ Apple silicon, platform-tools และ system image แบบ Play arm64 ลงโฟลเดอร์ SDK ที่คุณเลือก แอปสร้างแท็บเล็ตแนวนอนหนึ่งเครื่องชื่อ Android 16 Tablet แล้วเปิดในหน้าต่างของมันเอง แท็บเล็ตเริ่มต้นคือ 1920×1080 ที่ 320 dpi แนวนอน ปิด auto-rotate บนภาพ Android 16 Play

Google Play จะปรากฏหลังจากภาพนั้นเข้าที่แล้ว นี่ไม่ใช่ร้านค้าที่ถูกบรรจุมากับแอป บนหน้าโฮมของ Android เปิด Play Store แล้วลงชื่อเข้าใช้ SiliconPlay ไม่เห็นรหัสผ่านนั้น ถ้าคุณมี SDK ที่มี emulator, adb และ sdkmanager อยู่แล้ว ชี้แอปไปที่โฟลเดอร์นั้นได้ ไม่ต้องดาวน์โหลดสำเนาที่สอง

ถ้าการตั้งค่าหยุดเพราะ macOS ไม่มี JDK แอปจะบอกเอง /usr/bin/java บน macOS เป็นแค่ stub ข้อความในแอปชี้ไปที่ brew install openjdk@17 แล้วรันขั้นตอนแพ็กเกจนั้นอีกครั้ง

ติดตั้ง APK โดยไม่ต้องอยู่ใน IDE

เปิดอินสแตนซ์ก่อน แล้วค่อยติดตั้ง จากนั้นวางไฟล์ .apk หรือกด Command-I เพื่อนำเข้า APK แล้วติดตั้ง Split APK และไฟล์เก็บถาวร XAPK ไม่ถูกติดตั้งในรุ่นนี้ ดังนั้นบันเดิลที่มีแค่รูปแบบนั้นจะไม่เข้าไป นี่พอสำหรับเช็กปกติว่าบิลด์ติดตั้งแล้วเปิดได้หรือยัง คุณไม่ต้องเปิด Android Studio ค้างไว้ระหว่างแตะลองแอป

ติดตั้งด้วย adb ก็ได้ ไฟล์ที่คัดลอกแบบนั้นไปที่ /sdcard/SiliconPlay ภาพเหล่านี้ไม่เมานต์โฟลเดอร์ของเครื่องโฮสต์เป็นดิสก์ที่ใช้งานสด อย่าคาดว่าโฟลเดอร์ที่ใช้ร่วมกันจะโผล่ใน Android เอง

Pro Mode ปิดอยู่จนกว่าคุณจะเปิด มันอยู่ในทูลบาร์ เมนู View และ Settings เมื่อปิด หน้าต่างหลักมี Start, Stop และ Create New Instance เมื่อเปิด หน้าต่างหลักยังแสดงฮาร์ดแวร์ keymap และการวินิจฉัยเพิ่ม

รูทเป็นทางเลือก และเริ่มต้นแบบปิด

รูทเป็นทางเลือกและปิดไว้เป็นค่าเริ่มต้น ปล่อยปิดไว้สำหรับแท็บเล็ต Play ปกติ เปิดเฉพาะตอนที่คุณต้องการ adb root

แท็บเล็ตที่รูทใช้ภาพ Google APIs เพราะภาพ Play ปฏิเสธ adb root แท็บเล็ตนั้นไม่มี Play Store ภาพ APIs จะถูกดาวน์โหลดครั้งแรกที่คุณสร้าง ถ้าคุณต้องการทั้งการลงชื่อเข้า Play และรูท นั่นคือคนละแท็บเล็ต ไม่ใช่สวิตช์ที่พลิกบนภาพ Play ได้

ไม่มีส่วนขยายเคอร์เนล และไม่มีบริการเบื้องหลังให้ไปถอนทีหลัง ลบแอปเมื่อเลิกใช้ ไฟล์ SDK อยู่ที่โฟลเดอร์ SDK ที่คุณเลือก ไฟล์ของ SiliconPlay เองอยู่ที่ ~/Library/Application Support/SiliconPlay

คีย์บอร์ด ถ้าแอปที่คุณทดสอบไม่มีแป้น

การแตะตรงคือค่าเริ่มต้น ซึ่งมักเป็นสิ่งที่คุณต้องการสำหรับหน้าจอที่คุณสร้างเอง ถ้าคุณกำลังคลิกผ่านเกม keymap บนจอ และ รายการทางลัด คืออีกครึ่งหนึ่งของเรื่องนี้

คำถาม

ต้องรูทหรือไม่

ไม่ต้อง รูทเป็นทางเลือกและปิดไว้ตั้งแต่ต้น รูทใช้ภาพ Google APIs ภาพ Play ปฏิเสธ adb root และแท็บเล็ตที่รูทแล้วไม่มี Play Store

ติดตั้ง APK อย่างไร

เปิดอินสแตนซ์ก่อน แล้ววางไฟล์ APK หรือกด Command-I เพื่อนำเข้า ติดตั้งด้วย adb ก็ได้ Split APK และไฟล์ XAPK ไม่ถูกติดตั้งในรุ่นนี้ ไฟล์ที่คัดลอกด้วย adb ไปที่ /sdcard/SiliconPlay

ต้องเปิด Android Studio ค้างไว้ไหม

ไม่ต้อง ติดตั้ง APK แล้วลองใช้ได้โดยไม่ต้องมี IDE เต็มๆ มาขวาง แอปจะดาวน์โหลดอีมูเลเตอร์ทางการกับภาพ Play arm64 หรือใช้ SDK ที่คุณมีอยู่แล้ว

ใช้กับ Mac และ macOS รุ่นไหน

เฉพาะ Apple Silicon: M1, M2, M3, M4, M5 และรุ่นใหม่กว่า รวม Pro, Max และ Ultra รันแบบเนทีฟบน Apple Silicon ตอนนี้ทดสอบบน macOS Tahoe

ดาวน์โหลด SiliconPlay สำหรับ Mac

อ่านต่อในบล็อก: จับคู่คีย์บอร์ดและคอนโทรลเลอร์, ปุ่มลัดคีย์บอร์ด และ SiliconPlay บน M1 ถึง M5 และรุ่นใหม่กว่า หรือกลับไปที่ หน้าแรกของ SiliconPlay
