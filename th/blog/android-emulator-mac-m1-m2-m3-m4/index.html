อีมูเลเตอร์ Android สำหรับ Mac M1–M6

โดย Ryan Gibo · 26 ตุลาคม 2026

ถ้า Mac ของคุณเป็น Apple Silicon คุณมีคอมพิวเตอร์ ARM ที่เร็วอยู่แล้ว และ Android ก็เป็นระบบ ARM. SiliconPlay เอาสองอย่างนี้มาชนกัน. มันรัน Android 16 ตรงบนคอร์ของ Mac ผ่าน Hypervisor ของ Apple และวาดด้วย Metal. รันแบบเนทีฟบนคอร์ ARM ของ Mac. ฟรี ทั้งเล่นเกมและลองแอป.

Mac รุ่นไหนใช้ได้?

Mac ชิป Apple Silicon ทุกรุ่นตั้งแต่ M1 ถึง M6 รวม Pro, Max และ Ultra. เบื้องหลัง SiliconPlay ใช้ Android Emulator ทางการของ Google และทำงานแบบเนทีฟบนคอร์ ARM ของ Mac. ผมทดสอบบน macOS Tahoe และ macOS 27 Golden Gate. ถ้าคุณลองบน macOS เวอร์ชันอื่น บอกผมด้วยว่าเป็นอย่างไร.

ทำมาเพื่อเล่น

โอเวอร์เลย์คีย์บอร์ดและเกมแพดให้เดินด้วย WASD, โจมตีด้วย J และใช้สกิลด้วย 1-6 หรือจะแมปใหม่เองก็ได้. บน MacBook Pro ชิป M3 Max ผมวัดได้ถึง 60 fps ในเกม 3D ที่หนัก, สูงสุด 2560×1440, latency จากปุ่มถึงเกม 7 ถึง 43 ms. ผลเปลี่ยนตามเกม, เครื่อง และการตั้งค่า.

ใช้พัฒนาแอปได้ด้วย

ลอง APK บน Android ARM64 จริงได้โดยไม่ต้องเปิด IDE ทั้งชุด. รูทเป็นตัวเลือกและปิดมาให้. เล่นประจำวันระบบก็ยังปกติ. เปิดรูทเมื่อต้องเข้าถึงระบบเพื่อดีบักเท่านั้น.

ไม่มีของแถม

ไม่มีส่วนขยายเคอร์เนล, ไม่มีเซอร์วิสเบื้องหลัง และไม่มีโปรแกรมแถม. ลบแอปแล้วก็หาย.

  3. เปิด, เข้า Google Play แล้วติดตั้งเกมหรือแอป.

รันแอปที่ไม่มีบิลด์ ARM ได้ไหม?

ต้องรูทไหม?

ไม่ต้อง. รูทเป็นตัวเลือกและปิดมาให้.

ในบล็อกยังมี ทางเลือกแทน BlueStacks บน Mac และ ทางเลือกแทน MuMu Player บน Mac. หรือกลับไปที่ หน้า SiliconPlay.

แอปเดียวตั้งแต่ M1 ถึง M6

M1, M2, M3, M4, M5 และ M6 ไม่ใช่ไฟล์คนละชุด SiliconPlay เป็นแอป Mac เดียว Pro, Max และ Ultra คือชิปเดียวกันที่มีคอร์มากกว่า ไม่ใช่ผลิตภัณฑ์คนละตัว การเปิดครั้งแรกทำงานเหมือนกันทุกชิป: ใบอนุญาต Android SDK แล้ว command-line tools, อีมูเลเตอร์ Apple silicon, platform-tools และอิมเมจ Play arm64 ไปยังโฟลเดอร์ที่คุณเลือก

แท็บเล็ตชื่อ Android 16 Tablet แนวนอน 1920×1080 ที่ 320 dpi ปิดหมุนอัตโนมัติ เลข 2560×1440 ไม่ใช่ขนาดแท็บเล็ตนี้ มันมาจากการวัดเดียวที่เผยแพร่ บน MacBook Pro ชิป M3 Max: สูงสุด 60 fps ในเกม 3 มิติหนัก เรนเดอร์สูงสุด 2560×1440, 7–43 ms จากปุ่มถึงเกม ฉันไม่ได้เผยแพร่การวัดเดียวกันสำหรับ M1, M2, M4, M5 หรือ M6

ถ้าไม่มี JDK macOS จะแสดง stub ที่ /usr/bin/java ข้อความชี้ brew install openjdk@17 ชิปไม่เปลี่ยนประโยคนี้ แพ็กเกจที่ไม่มีไลบรารี ARM64 จะไม่รันบนชิปใดในรายการ เวอร์ชันนี้ไม่ติดตั้ง APK แยกส่วนหรือไฟล์ XAPK

ปุ่มลัด Cmd+I มาก่อน

  • Cmd+I ติดตั้ง APK ไฟล์เดียวเมื่ออินสแตนซ์ทำงานแล้ว เมนูแสดง Command-I การลากไฟล์คือการติดตั้งแบบเดียวกัน
  • F12 หรือ Command-K สลับระหว่างพิมพ์กับปุ่มเกม
  • F10 คือนิ้ว เมื่อกล่องโต้ตอบต้องการแตะ
  • Command-Shift-G แสดงหรือซ่อนปุ่มบนจอ
  • Shift-Escape ปล่อยนิ้วนิยมที่ค้าง
  • Escape ออกจากเต็มจอ นอกเต็มจอคือปุ่มย้อนกลับของ Android ขณะที่ภาพมีโฟกัส

สิ่งที่ชื่อชิปไม่ได้บอก

ถ้าเกมกระตุก ให้ลดกราฟิกของเกมก่อน อย่าสรุปจากชื่อ M1 หรือ M4 ว่า Mac ไม่เหมาะ ฉันทดสอบ macOS Tahoe และ macOS 27 Golden Gate เวอร์ชันอื่นให้ลอง แล้วส่งชิปกับเวอร์ชันมา ไม่รองรับ Intel Macs Vulkan ถูกวาดด้วย Metal เชดเดอร์เป็น safe math สำหรับใบไม้ เป็นเส้นทางเดียวกันทุกชิป
