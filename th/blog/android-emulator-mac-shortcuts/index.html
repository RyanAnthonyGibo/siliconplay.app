ปุ่มลัดของอีมูเลเตอร์ Android บน Mac: รายการคีย์บอร์ดใน SiliconPlay

โดย Ryan Gibo · 27 ตุลาคม 2026

นี่คือรายการปุ่มลัดของ SiliconPlay บน Mac ผมหยิบจากตัวแอปเอง (version 1.0.0, build 2) และ Command-I ซึ่งผมยืนยันแยกต่างหาก ผมไม่เอา shortcut จากอีมูเลเตอร์ตัวอื่นมาอุดช่อง และไม่แต่งชุดแป้นที่หาไม่เจอ ถ้าชุดไหนไม่ได้เขียนไว้ด้านล่าง แปลว่าผมตรวจไม่เจอ จึงไม่ใส่ไว้

SiliconPlay มีไว้สำหรับ Apple Silicon เท่านั้น: M1, M2, M3, M4, M5 และชิปรุ่นใหม่กว่าในสายเดียวกัน รันแบบเนทีฟบน Apple Silicon ตั้งแต่ M1 ถึง M5 และชิปรุ่นใหม่กว่า ผมทดสอบบน macOS Tahoe ถ้า macOS รุ่นอื่นทำไม่เหมือนกัน บอกผม

แป้นวิ่งไปที่ไหน

คลิกภาพ Android เพื่อให้คีย์บอร์ดเข้า keymap ทางลัดเมนูที่ใช้ปุ่ม Command ยังอยู่กับ macOS และจะไม่ถูกพิมพ์เข้าเกม ช่องข้อความที่ถูกโฟกัสจะเปลี่ยนทูลบาร์เป็น Typing จากนั้นคีย์บอร์ดเข้า Android เป็นข้อความ

รายการ Shortcuts ของบิลด์เดียวกันนี้ยังตั้งชื่อการกระทำต่อไปนี้ไว้ โดยที่ผมไม่มีชุดแป้นมาให้: เริ่มหรือหยุดอินสแตนซ์ที่เลือก สลับเต็มจอ ออกจากตัวอย่างเต็มจอ บันทึกภาพหน้าจอ เริ่มหรือหยุดอัดหน้าจอ แก้ไขผังแป้น สลับระหว่างการแตะตรงกับแป้นที่จับคู่ไว้ แสดงหรือซ่อนปุ่ม Android และซิงก์อินพุตข้ามอินสแตนซ์ที่กำลังรัน แป้นข้างป้ายแต่ละอันถูกวาดโดยเมนู ไม่ได้เก็บเป็นสตริงแยกที่อ่านได้ในบิลด์นี้ ผมจึงไม่แต่งขึ้นมา เปิด Shortcuts and limits ในแอป แล้วอ่านชุดแป้นบนสำเนาของคุณ

keymap เริ่มต้น ถ้าคุณยังไม่ได้แก้

พรีเซ็ตรายเกมจะแทนที่ชุดนี้เมื่อคุณกดรับ พรีเซ็ตของ Minecraft ใช้ left click เพื่อ break และใช้ E เปิด inventory แทน J กับ M จนกว่าคุณจะรับคำแนะนำ การแตะตรงยังเปิดอยู่ และ Game keys เหล่านี้จะยังไม่ถูกโหลด

คำถาม

อะไรใช้สลับระหว่างการพิมพ์กับปุ่มเกม

F12 หรือ Command-K Game keys ใช้ keymap Typing ส่งคีย์บอร์ดเข้า Android ช่องข้อความจะสลับไป Typing เอง

Escape ทำอะไร

Escape ออกจากเต็มจอ เมื่อหน้าต่างไม่ได้เต็มจอ Escape คือ Android Back ขณะที่ภาพถูกโฟกัส Shift-Escape ปล่อยนิ้วเสมือนทุกนิ้ว ระหว่างผูกปุ่มใหม่ Escape ยกเลิกการดักแป้น

นี่คือปุ่มลัดทั้งหมดในแอปหรือยัง

Command-I นำเข้า APK แล้วติดตั้งเข้า Android ที่เหลือในตารางคือทุกชุดที่ข้อความช่วยของ 1.0.0 เขียนไว้ รวม keymap เริ่มต้น มีอีกบางการกระทำที่ถูกตั้งชื่อในรายการ Shortcuts โดยไม่มีสตริงแป้นที่อ่านได้ในบิลด์นี้ เปิดแอปแล้วตรวจชุดนั้นเอง

ใช้บน Mac รุ่นไหนได้

Mac ชิป Apple Silicon: M1, M2, M3, M4 และ M5 รวม Pro, Max และ Ultra

ดาวน์โหลด SiliconPlay สำหรับ Mac

อ่านต่อในบล็อก: การจับคู่ปุ่มทำงานอย่างไร, ทดสอบ APK พร้อมรูทที่เป็นทางเลือก และ ใช้ได้บน Mac รุ่นไหน หรือกลับไปที่ หน้าแรกของ SiliconPlay
