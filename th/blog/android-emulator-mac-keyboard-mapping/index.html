SiliconPlay · บล็อก

จับคู่ปุ่มบนอีมูเลเตอร์ Android สำหรับ Mac: ปุ่มบนจอและเลย์เอาต์รายเกม

โดย Ryan Gibo · 27 ตุลาคม 2026

เกม Android ส่วนใหญ่รอให้นิ้วแตะ บน Mac คุณมีคีย์บอร์ด เมาส์ และบางคนมีคอนโทรลเลอร์อยู่แล้ว การจิ้มแทร็กแพดทั้งชั่วโมงจึงเมื่อยเร็ว SiliconPlay วางปุ่มทับภาพเกม แล้วผูกปุ่มนั้นเข้ากับแป้น นี่คือการจับคู่ปุ่มในอีมูเลเตอร์ Android บน Mac: แป้นหรือสติ๊กกลายเป็นการแตะ ตรงตำแหน่งที่คุณเลือก

SiliconPlay รันได้เฉพาะ Apple Silicon ตั้งแต่ M1 ถึง M5 และชิปรุ่นใหม่กว่าในสายเดียวกัน รันแบบเนทีฟบน Apple Silicon ตั้งแต่ M1 ถึง M5 และชิปรุ่นใหม่กว่า ผมทดสอบบน macOS Tahoe แล้ว ถ้าคุณอยู่บน macOS รุ่นอื่น เล่าให้ผมฟังว่าเกิดอะไรขึ้น

แตะตรงไปก่อน จนกว่าคุณจะอยากใช้แป้น

การแตะตรงคือค่าเริ่มต้น ตัวชี้ทำหน้าที่เป็นนิ้ว ซึ่งเหมาะกับเมนู ร้านค้า หรือแอปที่ไม่มี keymap เมื่อเกมที่รู้จักอยู่ด้านหน้า SiliconPlay อาจเสนอพรีเซ็ตจากชุมชน พรีเซ็ตนั้นจะปิดอยู่จนกว่าคุณจะกดรับ ไม่มี keymap ถูกโหลดเพียงเพราะเปิดแอป

คลิกที่ภาพ Android เพื่อให้คีย์บอร์ดเข้า keymap ถ้าช่องข้อความถูกโฟกัส ทูลบาร์จะขึ้นว่า Typing และแป้นจะเข้า Android แทนที่จะไปกดปุ่มบนจอ F12 หรือ Command-K สลับระหว่าง Typing กับ Game keys ทางลัดเมนูที่ใช้ปุ่ม Command ยังเป็นของ macOS

แป้นยังใช้ได้ขณะที่หน้าต่าง SiliconPlay ถูกโฟกัส ครั้งแรกที่แอปตามหน้าต่างของอีมูเลเตอร์เอง macOS จะขอสิทธิ์ Accessibility ก่อนคุณจะอนุญาต ให้โฟกัสหน้าต่าง SiliconPlay ไว้ แป้นก็ยังไปถึง

เลย์เอาต์เริ่มต้น: MMORPG (WASD)

เลย์เอาต์กลางที่มากับแอปชื่อ MMORPG (WASD) ไม่ได้ผูกกับ package ใด จึงไม่ถูกเสนอให้อัตโนมัติ คุณใส่ให้เกมไหนก็ได้ แล้วเลื่อนจุดที่ยังไม่ตรง สติ๊กแตะตรงกลางปุ่มของมัน แล้วไถออกไปตราบใดที่ยังกดแป้นค้าง พอปล่อย สติ๊กจะเลื่อนกลับมาที่กลาง

โน้ตของพรีเซ็ตบอกให้ปรับในตัวแก้ไข มองตำแหน่งพวกนี้เป็นแค่จุดตั้งต้น ค่าเป็นสัดส่วนของภาพเกม ตั้งแต่ 0 ถึง 1 จุดกำเนิดอยู่มุมซ้ายบน จึงย่อขยายตามเมื่อขนาดหน้าต่างเปลี่ยน

เลื่อนปุ่มจนกว่าจะทับตำแหน่งในเกม

Edit layout เปิดตัวแก้ไข keymap ลากปุ่มเพื่อย้าย คลิกปุ่มนั้นเพื่อผูกแป้นหรือปุ่มเมาส์ใหม่ ลาก gold dot เพื่อปรับขนาด เพิ่มจอยสติ๊ก WASD, การลากกล้อง, การแตะ, การกดค้าง, การปัด หรือการย้ำได้ Done บันทึก Cancel คืนโปรไฟล์กลับไปตอนที่เปิดตัวแก้ไข Escape ยกเลิกการดักแป้นถ้าคุณกำลังผูกใหม่

บนหน้าต่างอีมูเลเตอร์แยกต่างหาก มีฟองแก้วตามหน้าไป ลากฟองเพื่อย้าย คลิกเพื่อเปิดโอเวอร์เลย์ ความทึบ ขนาด แก้ไข และรีเซ็ต จุดนั้นถูกจำไว้ในโปรไฟล์ Command-Shift-G สลับการแสดงโอเวอร์เลย์ พื้นที่ว่างบนภาพยังคลิกเข้าเกมได้

F10 สลับไปการแตะตรง ซึ่งตรงกว่าเมื่อเมนูต้องการนิ้วจริง ไม่ใช่ปุ่มที่จับคู่ไว้ Shift-Escape ปล่อยนิ้วเสมือนทุกนิ้ว ถ้ามีนิ้วค้างกดอยู่

คอนโทรลเลอร์ใช้ปุ่มชุดเดียวกัน

ชิปหนึ่งตัวฟังอินพุตได้มากกว่าหนึ่งทาง ในเลย์เอาต์เริ่มต้น skill 1 คือแป้น 1 และ gamepad X ส่วนกระโดดคือ Space และ gamepad B ตอนผูกใหม่ คุณยังผูก face buttons, shoulders, triggers, D-pad, menu และ options ได้ คอนโทรลเลอร์ไม่ใช่ผังที่สอง มันกดปุ่มบนจอชุดเดียวกับที่คีย์บอร์ดกด

เลย์เอาต์แยกตามเกม

บางแอปมีพรีเซ็ตของตัวเอง จับคู่ด้วย package เมื่อเกมนั้นอยู่ด้านหน้า SiliconPlay จะเสนอให้แล้วรอ คุณกดรับก่อน แล้วค่อยลากจุดที่ยังไม่ทับภาพ ข้อความในไฟล์พวกนี้เรียกว่าพรีเซ็ตชุมชน

Minecraft เป็นตัวอย่างชัดของเลย์เอาต์ที่ไม่ได้ใช้ผังกลาง พรีเซ็ตใช้ WASD เดิน, คลิกซ้ายเพื่อทุบ, คลิกขวาเพื่อใช้, Space กระโดด, E เปิด inventory, 1 ถึง 3 สำหรับ hotbar และเมาส์ขวาเพื่อมอง เกมที่ปุ่มกระจายคนละมุมต้องจัดแบบนี้ ไม่ใช่แถว MMORPG ตามขอบล่าง

บิลด์เดียวกันนี้มีพรีเซ็ตของ Genshin Impact, Roblox, Call of Duty Mobile และ Clash of Clans ด้วย ผมจะไม่แกล้งบอกว่าเลย์เอาต์เดียวใช้ได้กับทุกเกม รับคำแนะนำ เล่นสักครู่ แล้วขยับชิป

ไปหา keymap จากในเน็ต

สำเนาที่วางใจได้คือชุดในแอป ถ้าคุณเจอเลย์เอาต์ที่คนอื่นโพสต์ ไฟล์ต้องเป็น keymap ของ SiliconPlay คือ JSON ที่ format id เป็น stardroid.keymap ไฟล์ที่ไม่ใช่ JSON ที่ถูกต้องของรูปแบบนี้จะถูกปฏิเสธ ตำแหน่งในไฟล์ที่แชร์กันถูกวาดไว้สำหรับจอของคนอื่น ดังนั้นเปิดตัวแก้ไขแล้วจัดปุ่มให้ตรงกับจอคุณ

Pro Mode อยู่ในทูลบาร์ เมนู View และ Settings มันโชว์ฮาร์ดแวร์ keymap และการวินิจฉัยบนหน้าต่างหลัก และจะปิดอยู่จนกว่าคุณจะเปิดเอง ฟองบนหน้าต่างอีมูเลเตอร์ยังมีแก้ไข โอเวอร์เลย์ ความทึบ ขนาด และรีเซ็ต

คำถาม

SiliconPlay ใช้บน Mac รุ่นไหนได้

ไม่ได้ ใช้ได้เฉพาะ Apple Silicon คือ M1, M2, M3, M4, M5 และชิปรุ่นใหม่กว่าในสายเดียวกัน

ต้องใช้ keymap เสมอหรือเปล่า

ไม่ต้อง การแตะตรงคือค่าเริ่มต้น พรีเซ็ตที่แอปเสนอจะยังไม่ทำงานจนกว่าคุณจะกดรับ

ใช้คอนโทรลเลอร์ได้ไหม

ได้ ปุ่มเกมแพดกดชิปบนจอชุดเดียวกับคีย์บอร์ด เลย์เอาต์ MMORPG จับคู่สกิลบางปุ่มกับกระโดดไว้ให้แล้ว

จะหา keymap ของเกมตัวเองได้จากไหน

ใช้พรีเซ็ตที่แอปเสนอ หรือใส่ MMORPG (WASD) แล้วแก้เอง ไฟล์จากที่อื่นต้องเป็น JSON ของ stardroid.keymap ที่ถูกต้อง

ดาวน์โหลด SiliconPlay สำหรับ Mac

อ่านต่อในบล็อก: ปุ่มลัดของคีย์บอร์ด, ใช้ SiliconPlay ทดสอบ APK และ SiliconPlay บน M1 ถึง M5 และรุ่นใหม่กว่า หรือกลับไปที่ หน้าแรกของ SiliconPlay

SiliconPlay ไม่ได้เกี่ยวข้องกับ Apple Inc. หรือ Google LLC. Android เป็นเครื่องหมายการค้าของ Google LLC. Mac, macOS และ Metal เป็นเครื่องหมายการค้าของ Apple Inc.
