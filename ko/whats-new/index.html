SiliconPlay 1.1.2의 새로운 기능

버전 1.1.2 (빌드 5) · Apple Silicon M1–M6 · 2026년 11월 20일

SiliconPlay 1.1.2은 Apple Silicon Mac용 안드로이드 에뮬레이터의 무료 업데이트입니다. 이제 스스로 최신 상태를 유지하고, 실행하면 바로 전체 메인 창이 열리며, 새 인스턴스 목록은 클릭하면 기대한 대로 반응합니다.

Mac용 SiliconPlay 1.1.2 다운로드

1.1.2: 부드러운 스크롤과 여러분의 로그로 만든 수정

버전 1.1.2(빌드 5)는 사용자들이 보내 준 로그를 바탕으로 만들었고, 스크롤과 확대/축소를 위한 새 컨트롤이 추가되었습니다.

  • macOS Sequoia 이하에서 Android가 더 안정적으로 시작됩니다. 최신 Android Emulator가 제대로 시작되지 않으면 SiliconPlay가 옆에 둔 테스트된 에뮬레이터 버전을 사용합니다.
  • Android가 시작되는 동안 그래픽 오류가 반복되면 SiliconPlay가 알아서 더 안전한 그래픽 모드로 바꾸고 알려 줍니다.
  • Android가 그냥 멈췄을 때 잘못 표시되던 “포트 사용 중” 오류가 더 이상 나오지 않습니다.
  • 방사형 메뉴에 마우스 휠과 트랙패드용 자동, 핀치, 스크롤 모드가 추가되었습니다. 자동은 앱에서는 스크롤하고 게임에서는 핀치 줌을 합니다.
  • 트랙패드 스크롤이 부드러워져 Android가 시작되는 순간부터 손가락을 그대로 따라오고, 손을 떼도 목록이 계속 미끄러집니다.
  • 스크롤과 핀치 감도: 방사형 메뉴의 Speed 조각은 0.25×부터 3×까지이고, 설정에는 각각의 슬라이더와 1×로 되돌리는 Reset이 있습니다.
  • 인스턴스 중지가 더 안정적입니다. SiliconPlay는 Android가 스스로 종료되도록 기다린 뒤 닫습니다.

1.1.1: Android가 더 안정적으로 시작됩니다

버전 1.1.1(빌드 4)은 수정 업데이트입니다. 특히 macOS Sequoia 이하이거나 Android Emulator가 새 버전으로 자동 업데이트된 뒤, 부팅 중 “could not start”로 멈추던 Mac에서 Android가 시작되는 데 도움이 될 것입니다.

  • Android를 시작하기 전에 SiliconPlay가 Android Emulator 버전을 읽습니다. macOS Sequoia 이하에서 테스트한 버전보다 새로운 에뮬레이터라면 OpenGL ES 그래픽 모드로 시작합니다.
  • 부팅 중 Android가 멈추면 SiliconPlay가 포기하지 않고 더 안전한 그래픽 모드를 하나씩 시도합니다.
  • 그래도 Android가 시작되지 않으면 메시지에 실제 원인이 표시되고, Copy Diagnostics로 자세한 내용을 복사해 저에게 보낼 수 있습니다. 로그는 ~/Library/Logs/SiliconPlay에 있습니다.

1.1.0의 새로운 기능:

자동 업데이트

  • SiliconPlay는 하루에 한 번쯤 새 버전이 있는지 확인합니다. 새 버전이 나오면 한 번만 알려 줍니다. Later를 누르면 다음 버전이 나올 때까지 그 버전은 숨겨집니다.
  • SiliconPlay → Check for Updates…로 바로 확인할 수 있습니다. 매일 확인하지 않으려면 Settings에서 Check for updates automatically를 끄세요.
  • Download를 누르면 디스크 이미지가 다운로드 폴더에 저장되고 바로 열립니다. 앱은 Developer ID로 서명되었고 Apple의 공증을 받았습니다.

메인 창과 인스턴스 목록

  • 앱을 열면 바로 전체 메인 창이 나타나고 모든 버튼이 보입니다.
  • 클릭하면 인스턴스가 선택됩니다. 이미 선택된 인스턴스도 마찬가지입니다.
  • 선택된 것을 포함해 어떤 인스턴스든 오른쪽 클릭하면 Start, Stop, Settings…, Rename…, Duplicate, Show in Finder, Delete가 나옵니다.
  • 인스턴스를 더블 클릭하면 설정이 열립니다.
  • mouse look이 있는 게임 프리셋이 더 이상 SiliconPlay 자체 창에서 클릭, 입력, 스크롤을 막지 않습니다.

마우스 휠로 핀치 줌

  • 안드로이드 앱에서 마우스 휠이 이제 커서 위치를 기준으로 핀치 줌을 합니다. 터치스크린에서 두 손가락을 쓰는 것과 같아서, 지도와 게임 카메라가 휴대폰에서처럼 확대됩니다. 목록을 스크롤하려면 Shift를 누른 채 돌리세요.
  • Settings → Scroll wheel에서 Scroll the page 또는 Camera look으로 바꿀 수 있습니다. 이 모드에서는 Option을 누른 채 핀치 줌을 합니다.

1.0에서 업데이트하는 방법

  1. SiliconPlay 1.1.2을 다운로드하고 디스크 이미지를 엽니다.
  2. SiliconPlay를 종료한 뒤 새 앱을 응용 프로그램 폴더로 끌어다 놓고 기존 앱을 대체합니다. 인스턴스는 앱 밖에 저장되므로 그대로 남습니다.
  3. 키보드 조작이 먹히지 않으면 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 SiliconPlay를 다시 허용하세요. 앱을 교체하면 macOS가 다시 허용을 요청할 수 있습니다.
  4. 앞으로는 새 버전이 앱 안에서 안내됩니다.

지원하는 Mac

SiliconPlay는 Apple Silicon Mac(M1~M6) 전용입니다. Intel Macs와는 호환되지 않습니다. 버전 1.1.0은 macOS Tahoe와 macOS 27 Golden Gate에서 테스트했습니다.
