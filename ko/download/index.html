Mac용 SiliconPlay 받기

다운로드를 준비하는 중…

SiliconPlay는 M1부터 M6까지 Apple silicon Mac용 무료 Android 에뮬레이터입니다. 파일은 SiliconPlay.dmg, 버전 1.1.3입니다. DMG는 Mac 앱입니다. Android 자체는 처음 열 때 받아집니다.

Mac용 SiliconPlay 받기

파일이 도착한 다음

  1. DMG를 열고 SiliconPlay를 응용 프로그램으로 끌어다 놓으세요.
  2. SiliconPlay를 여세요. 첫 실행은 Android SDK 라이선스에 동의하고 Apple silicon 에뮬레이터, platform-tools, Play arm64 이미지를 받습니다. emulator, adb, sdkmanager가 있는 SDK가 있으면 그 폴더를 가리키면 됩니다.
  3. Android 16 태블릿이 뜨면(1920×1080, 320 dpi, 가로) Google Play에 들어가거나 APK 하나를 설치하세요.

필요한 것

  • Apple silicon Mac, M1부터 M6, Pro, Max, Ultra 포함.
  • macOS Tahoe와 macOS 27 Golden Gate에서 확인했습니다. 다른 버전이면 해보고 무슨 일이 있었는지 알려 주세요.
  • Intel Macs와는 호환되지 않습니다.

단축키, Cmd+I가 먼저

  • Cmd+I는 Android가 실행 중일 때 APK 하나를 설치합니다. 메뉴에는 Command-I로 나옵니다. 끌어다 놓기도 같은 설치입니다.
  • F12 또는 Command-K는 입력과 게임 키를 바꿉니다.
  • F10은 대화상자가 손가락을 원할 때의 직접 터치입니다.
  • Command-Shift-G는 화면 위 버튼을 보이거나 숨깁니다.
  • Shift-Escape는 눌린 채로 남은 가상 손가락을 뗍니다.
  • Escape는 전체 화면을 끝냅니다. 밖에서는 화면이 포커스인 동안 Android 뒤로입니다.

JDK가 없어 설정이 멈추면 macOS가 /usr/bin/java 스텁을 보여주는 것입니다. 메시지는 brew install openjdk@17을 가리킵니다. 설치한 뒤 패키지 단계를 다시 실행하세요. 긴 설명은 블로그에 있고, 각 도구의 자리는 비교.
