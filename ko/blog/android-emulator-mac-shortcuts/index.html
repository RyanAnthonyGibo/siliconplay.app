맥 안드로이드 에뮬레이터 단축키: SiliconPlay 키보드 목록

작성: Ryan Gibo · 2026년 10월 27일

이것은 맥에서 SiliconPlay의 키보드 단축키 목록입니다. 앱 자체(version 1.0.0, build 2)에서 가져왔고, Command-I는 따로 확인했습니다. 다른 에뮬레이터의 단축키로 빈칸을 채우지 않았고, 없는 조합을 만들지 않았습니다. 아래에 적히지 않은 조합은 확인하지 못한 것이므로 여기에 없습니다.

SiliconPlay는 Apple Silicon 전용입니다. M1, M2, M3, M4, M5와 그 계열의 더 새로운 칩입니다. Apple Silicon의 ARM 코어에서 네이티브로 돕니다. M1부터 M5와 그 이후입니다. 저는 macOS Tahoe에서 시험했습니다. 다른 macOS에서 다르게 동작하면 알려 주십시오.

키가 가는 곳

안드로이드 화면을 클릭하면 키보드가 키 맵으로 갑니다. Command 키 메뉴 단축키는 macOS에 남으며, 게임 안에 입력되지 않습니다. 글 칸에 포커스가 있으면 도구 막대가 Typing으로 바뀌고, 키보드는 글자로 안드로이드에 들어갑니다.

같은 빌드의 Shortcuts 목록은 다음 동작의 이름도 적고 있으며, 여기에 조합은 없습니다. 선택한 인스턴스를 시작하거나 멈추기, 전체 화면 전환, 전체 화면 미리보기 나가기, 스크린샷 저장, 화면 녹화 시작 또는 중지, 키 맵 편집, 직접 터치와 매핑된 키 전환, 안드로이드 버튼 보이기 또는 숨기기, 실행 중인 인스턴스 사이에서 입력 동기화입니다. 각 이름 옆의 키는 메뉴가 그립니다. 이 빌드에서는 따로 읽을 수 있는 문자열로 저장되어 있지 않으므로 만들지 않습니다. 앱에서 Shortcuts and limits를 열고, 자신의 사본에 적힌 조합을 읽으십시오.

아직 고치지 않았을 때의 기본 키 맵

키 맵이 켜지기 전에는 Game keys가 별로 쓸모가 없습니다. 일반 프리셋은 MMORPG (WASD)입니다. 한 게임에 묶여 있지 않습니다. 적용한 다음 버튼을 옮기십시오. 편집 절차 전체는 맥에서의 키 매핑에 있습니다. 그 파일의 연결은 다음과 같습니다.

게임별 프리셋은 받아들이는 순간 이 연결을 바꿉니다. 예를 들어 Minecraft 프리셋은 J와 M 대신 left click으로 break하고 E로 inventory를 엽니다. 제안을 받아들이기 전까지는 직접 터치가 켜져 있고, 이 Game keys는 불러오지 않습니다.

질문

입력과 게임 키를 무엇으로 바꿉니까?

F12 또는 Command-K입니다. Game keys는 키 맵을 씁니다. Typing은 키보드를 안드로이드로 보냅니다. 글 칸은 스스로 Typing으로 바뀝니다.

Escape는 무엇을 합니까?

전체 화면에서 나갑니다. 창이 전체 화면이 아닐 때, 화면이 포커스되어 있으면 Escape는 Android Back입니다. Shift-Escape는 가상 손가락을 모두 뗍니다. 다시 묶는 중에는 Escape가 가로채기를 취소합니다.

이것이 앱의 단축키 전부입니까?

Command-I는 APK를 가져와 안드로이드에 설치합니다. 표의 나머지는 1.0.0 도움말이 글로 적어 둔 조합과 기본 키 맵입니다. Shortcuts 목록에는 이 빌드에서 읽을 수 있는 키 문자열이 없는 동작 이름도 몇 개 있습니다. 그 조합은 앱에서 확인하십시오.

어떤 Mac에서 됩니까?

되지 않습니다. Apple Silicon만 됩니다. M1, M2, M3, M4, M5와 더 새로운 칩입니다.
