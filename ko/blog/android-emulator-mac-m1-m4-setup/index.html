맥북 M1·M4 안드로이드 에뮬레이터(앱플레이어) 설치 방법

작성: Ryan Gibo · 2026년 10월 28일

“맥북 M1 안드로이드 에뮬레이터”나 “맥 M4 앱플레이어”를 검색하면 Apple Silicon 이전에 쓰인 글이 많이 나옵니다. 여기서는 짧게 지금 기준으로 정리합니다. M 칩 Mac에서 제가 Apple Silicon용으로 만드는 SiliconPlay로 안드로이드 게임과 앱을 돌리는 방법입니다.

무엇을 설치하나요

SiliconPlay 안에서는 Google의 공식 Android Emulator가 Mac의 ARM 코어에서 네이티브로 돌아갑니다. 그 바깥의 Mac 앱, 즉 인터페이스와 조작 매핑은 제가 처음부터 직접 짰습니다. Apple Silicon 전용이고 M1부터 M5까지 지원하며, macOS Tahoe에서 테스트했습니다.

준비물

  • M1, M2, M3, M4, M5 칩 Mac(Pro, Max, Ultra 포함).
  • macOS Tahoe. 제가 테스트한 버전입니다.
  • Google Play에서 설치하려면 Google 계정.

설치 순서

  1. SiliconPlay.dmg를 내려받습니다.
  2. DMG를 열고 SiliconPlay를 응용 프로그램으로 끌어다 놓습니다.
  3. SiliconPlay를 열고 Android를 시작합니다.
  4. Google Play에 로그인하고 게임과 앱을 설치합니다. APK 파일을 설치하려면 Command-I를 누릅니다.
  5. Android 화면을 클릭합니다. 기본값은 직접 터치입니다. 키보드로 하려면 SiliconPlay가 게임에 맞춰 제안하는 프리셋을 수락하거나, MMORPG (WASD)를 적용한 뒤 버튼을 옮깁니다.

Mac용 SiliconPlay 받기

먼저 익혀 둘 단축키

  • Command-I: APK를 가져와 Android에 설치합니다.
  • F12 또는 Command-K: Typing과 Game keys를 전환합니다.
  • Command-Shift-G: 화면의 게임 버튼을 보이거나 숨깁니다.
  • Escape: 전체 화면을 나갑니다. 전체 화면이 아닐 때는 Android 뒤로 가기입니다.
  • Shift-Escape: 모든 가상 손가락을 뗍니다.

M1과 M4, 무엇이 다른가요?

앱은 M1부터 M5까지 모든 칩에서 같습니다. 칩별 벤치마크는 공개하지 않았으므로 M1이나 M4 수치는 적지 않겠습니다. 새 칩일수록 여유가 있고, 무거운 3D 게임에서 차이가 가장 큽니다. 게임이 끊기면 먼저 게임의 그래픽 설정을 낮춰 보세요. ARM 빌드가 없는 앱은 어느 칩에서도 실행되지 않지만, 요즘 앱은 대부분 ARM 빌드를 포함합니다.

질문

맥북 M1에서 되나요?

네. M1, M2, M3, M4, M5와 Pro, Max, Ultra 모두 됩니다.

macOS는 어떤 버전이 필요한가요?

SiliconPlay는 macOS Tahoe에서 테스트했습니다. 다른 버전에서 다르게 동작하면 알려 주세요.

Google 에뮬레이터인가요?

안쪽은 그렇습니다. Google 공식 Android Emulator입니다. 인터페이스와 조작 매핑은 SiliconPlay가 처음부터 새로 짠 것입니다.

루팅이 필요한가요?

아니요. 루팅은 선택 사항이고 기본으로 꺼져 있습니다. 필요한 개발자를 위해 있습니다.
