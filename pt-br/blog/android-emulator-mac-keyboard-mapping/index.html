Mapeamento de teclado no emulador de Android para Mac: botões na tela e layout por jogo

Por Ryan Gibo · 27 de outubro de 2026

A maioria dos jogos de Android espera um dedo. No Mac você já tem teclado, mouse e, se quiser, um controle, e ficar uma hora no trackpad cansa. O SiliconPlay desenha botões em cima da imagem do jogo e amarra esses botões em teclas. É isso o mapeamento de teclado neste emulador de Android para Mac: uma tecla ou um analógico vira um toque, no lugar que você escolheu.

O SiliconPlay só roda em Apple Silicon, nos M1, M2, M3, M4, M5 e nos chips mais novos dessa linha. Roda nativo em Apple Silicon, do M1 ao M5 e nos mais novos. Eu testei no macOS Tahoe. Se você estiver em outra versão do macOS, me conta o que aconteceu.

Toque direto, até você querer teclas

O toque direto é o padrão. O ponteiro é um dedo, que é o que você quer num menu, numa loja ou em qualquer app sem keymap. Quando um jogo conhecido está na frente, o SiliconPlay pode oferecer um preset da comunidade. O preset fica desligado até você aceitar. Nenhum keymap entra só porque o app abriu.

Clique na imagem do Android para o teclado ir para o keymap. Se um campo de texto estiver focado, a barra diz Typing e as teclas vão para o Android, em vez dos botões. F12 ou Command-K alterna entre Typing e Game keys. Atalhos de menu com a tecla Command continuam com o macOS.

As teclas continuam valendo enquanto a janela do SiliconPlay está focada. Na primeira vez que o app segue a janela do próprio emulador, o macOS pede Accessibility. Esse pedido existe só para o app conseguir seguir a janela do emulador. Enquanto você não permitir, deixe a janela do SiliconPlay focada que as teclas ainda caem no lugar.

O layout padrão: MMORPG (WASD)

O layout genérico que vem com o app se chama MMORPG (WASD). Ele não está preso a um pacote, então não é sugerido sozinho. Você aplica em qualquer jogo e depois corrige o que ficar fora. O analógico toca no centro do botão e desliza para fora enquanto alguma tecla dele está segurada. Quando você solta, ele volta para o centro.

As notas desse preset pedem para ajustar no editor. Trate as posições como ponto de partida. Elas são frações da imagem do jogo, de 0 a 1, com origem no canto superior esquerdo, então acompanham quando a janela muda de tamanho.

Mova os botões até eles caírem em cima do jogo

Edit layout abre o editor de keymap. Arraste um botão para mover. Clique nele para reatribuir uma tecla ou um botão do mouse. Arraste o ponto dourado para redimensionar. Dá para adicionar um joystick WASD, um arraste de câmera, um toque, um toque longo, um swipe ou uma repetição. Done salva. Cancel devolve o perfil ao que era quando você abriu o Edit. Escape cancela a captura de tecla se você estiver no meio de um rebind.

Na janela separada do emulador, uma bolha de vidro acompanha a janela. Arraste a bolha para movê-la. Clique nela para a sobreposição, a opacidade, o tamanho, editar e resetar. Esse ponto fica salvo no perfil. Command-Shift-G liga e desliga a sobreposição. O espaço vazio da imagem ainda clica no jogo.

F10 passa para o toque direto, o caminho mais simples quando um menu quer um dedo de verdade em vez de um botão mapeado. Shift-Escape solta todo dedo virtual se algum ficar preso.

O controle usa os mesmos botões

Um chip pode ouvir mais de uma entrada. No layout padrão, a habilidade 1 é ao mesmo tempo a tecla 1 e gamepad X, e o pulo é Space e gamepad B. Na hora de reatribuir um chip, você também pode ligar os botões de face, shoulders, triggers, D-pad, menu e options. O controle não é um segundo esquema. Ele aperta os mesmos botões da tela que o teclado aperta.

Layouts por jogo

Alguns apps têm o próprio preset, casado pelo pacote. Quando esse jogo está na frente, o SiliconPlay oferece e espera. Aceite, depois arraste o que não acertar a arte. O texto desses arquivos chama isso de preset da comunidade.

Minecraft é um exemplo claro de layout que não é o genérico. O preset dele usa WASD para mover, clique esquerdo para quebrar, clique direito para usar, Space para pular, E para o inventário, 1 a 3 para a hotbar e o botão direito do mouse para olhar. Um jogo cujos botões ficam em cantos diferentes precisa desse tipo de ajuste, não da fileira MMORPG embaixo.

A mesma build também traz presets para jogos como Genshin Impact, Roblox, Call of Duty Mobile, Clash of Clans e outros. Não vou fingir que um layout serve para todos. Aceite a sugestão, jogue um minuto e mova os chips.

Achar um keymap na internet

A cópia confiável é a que está no app. Se você achar um layout que alguém publicou, tem que ser um keymap do SiliconPlay: JSON cujo id de formato é stardroid.keymap. Arquivo que não for JSON válido nesse formato é recusado. As posições num arquivo compartilhado foram desenhadas para a tela de outra pessoa, então abra o editor e alinhe os botões com a sua.

Pro Mode, na barra de ferramentas, no menu View e em Settings, mostra hardware, keymaps e diagnósticos na janela principal. Fica desligado até você ligar. A bolha na janela do emulador continua com editar, sobreposição, opacidade, tamanho e resetar.

Perguntas

Em quais Macs o SiliconPlay roda?

Não. Só Apple Silicon: M1, M2, M3, M4, M5 e os chips mais novos dessa linha.

Preciso usar um keymap?

Não. O toque direto é o padrão. Um preset sugerido fica desligado até você aceitar.

Dá para usar controle?

Sim. Amarre os botões do gamepad nos mesmos chips da tela que o teclado. O layout MMORPG já faz isso para algumas habilidades e para o pulo.

Onde eu pego um keymap do meu jogo?

Use o preset que o app oferece, ou aplique MMORPG (WASD) e edite. Um arquivo de outro lugar tem que ser JSON válido de stardroid.keymap.
