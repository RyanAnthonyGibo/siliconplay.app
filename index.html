Free Android emulator for Apple Silicon Macs

SiliconPlay

SiliconPlay is a free Android emulator for Apple Silicon Macs (M1, M2, M3, M4, M5, and newer). It runs Android games and Android development directly on the Mac’s ARM cores through Apple’s Hypervisor framework, and graphics are drawn by Metal. Nothing is translated from x86.

Download SiliconPlay for Mac

Features

  • Native ARM64 Android 16 on Apple silicon.
  • Vulkan drawn by Metal, with shaders compiled in safe math mode so foliage renders correctly.
  • Built-in keyboard and gamepad overlay: WASD to move, J to attack, 1–6 for skills.
  • No kernel extensions, no background services, no bundled software.

Measured on a MacBook Pro with M3 Max

  • Up to 60 fps in a demanding 3D game.
  • Render resolution up to 2560×1440.
  • 7–43 ms measured key-to-game input latency.

Requires a Mac with Apple silicon (M1 or later) and macOS 14 or later. Results vary by game, Mac and settings.

FAQ

Which Macs does it work on?

Mac computers with Apple silicon (M1, M2, M3, M4, M5, and newer) running macOS 14 or later.

Is my game account safe?

SiliconPlay includes optional root and does not modify games. Follow each game’s terms of service.

Is it free?

Yes. SiliconPlay is free. Supporting the project is optional.

Is the source code available?

No. Licenses for third-party components are included with the app.
