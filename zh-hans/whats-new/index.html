SiliconPlay 1.1.2 新功能

版本 1.1.2（构建 5）· Apple Silicon M1–M6 · 2026 年 11 月 20 日

SiliconPlay 1.1.2 是 Apple 芯片 Mac 上安卓模拟器的免费更新。现在它会自己保持最新，启动后直接打开完整的主窗口，全新的实例列表点击后的反应也和你预想的一样。

1.1.2：流畅滚动，以及根据你们的日志所做的修复

1.1.2 版（版本号 5）根据用户发来的日志制作，并新增了滚动和缩放控制。

  • 在 macOS Sequoia 及更早版本上，Android 启动更可靠。当最新的 Android Emulator 在这些系统上无法正常启动时，SiliconPlay 会改用放在旁边的经过测试的模拟器版本。
  • 如果 Android 启动时反复出现图形错误，SiliconPlay 会自动切换到更安全的图形模式并提示你。
  • Android 只是停止运行时，不再误报“端口被占用”。
  • 径向菜单中新增鼠标滚轮和触控板的自动、捏合和滚动模式。自动模式在应用中滚动，在游戏中捏合缩放。
  • 触控板滚动流畅，从 Android 启动的那一刻起就跟随你的手指，松手后列表还会继续滑动。
  • 滚动和捏合灵敏度：径向菜单中的 Speed 扇区可在 0.25× 到 3× 之间调节，设置中两者各有一个滑块，并可用 Reset 恢复到 1×。
  • 停止实例更稳定：SiliconPlay 会先让 Android 自行关闭，再将其关闭。

1.1.1：Android 启动更可靠

1.1.1 版（构建 4）是一个修复更新。在启动过程中出现“could not start”而停住的 Mac 上，它应该能帮助 Android 正常启动，尤其是 macOS Sequoia 及更早版本，或 Android Emulator 自动更新到新版本之后。

  • 启动 Android 之前，SiliconPlay 会读取 Android Emulator 的版本。在 macOS Sequoia 及更早版本上，如果模拟器比测试过的版本更新，就会以 OpenGL ES 图形模式启动。
  • 如果 Android 在启动过程中停住，SiliconPlay 会依次尝试更安全的图形模式，而不是直接放弃。
  • 如果 Android 仍然无法启动，提示会显示真正的原因，Copy Diagnostics 会复制详细信息，方便你发给我。日志位于 ~/Library/Logs/SiliconPlay。

1.1.0 新增：

自动更新

  • SiliconPlay 大约每天检查一次是否有新版本。有新版本时只提醒一次。点 Later 会隐藏该版本，直到下一个版本发布。
  • SiliconPlay → Check for Updates… 会立即检查。如不需要每天检查，可在 Settings 中关闭 Check for updates automatically。
  • Download 会把磁盘映像保存到“下载”文件夹并打开。应用使用 Developer ID 签名，并已通过 Apple 公证。

主窗口与实例列表

  • 应用启动后直接打开完整的主窗口，所有控制按钮一目了然。
  • 单击即可选中实例，已选中的实例也一样。
  • 右键点按任意实例（包括已选中的），即可看到 Start、Stop、Settings…、Rename…、Duplicate、Show in Finder 和 Delete。
  • 双击实例即可打开其设置。
  • 带有 mouse look 的游戏预设不再阻挡 SiliconPlay 自身窗口中的点击、输入和滚动。

用鼠标滚轮双指缩放

  • 在安卓应用中，鼠标滚轮现在会以光标位置为中心进行双指缩放，就像在触摸屏上用两根手指操作。地图和游戏镜头的缩放方式和手机上一样。如需滚动列表，请按住 Shift。
  • 可在 Settings → Scroll wheel 中改为 Scroll the page 或 Camera look。在这两种模式下，按住 Option 即可缩放。

如何从 1.0 更新

  1. 下载 SiliconPlay 1.1.2 并打开磁盘映像。
  2. 退出 SiliconPlay，把新应用拖到“应用程序”文件夹并替换旧版本。实例保存在应用之外，所以都会保留。
  3. 如果键盘控制失灵，请打开“系统设置”→“隐私与安全性”→“辅助功能”，重新允许 SiliconPlay。替换应用后，macOS 可能会再次请求此权限。
  4. 以后有新版本时，会直接在应用内提示。

支持哪些 Mac

SiliconPlay 仅支持搭载 Apple 芯片的 Mac（M1 至 M6），不兼容 Intel Macs。1.1.0 版已在 macOS Tahoe 和 macOS 27 Golden Gate 上测试。
