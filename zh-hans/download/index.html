SiliconPlay 是面向 M1 到 M6 Apple 芯片 Mac 的免费安卓模拟器。文件是 SiliconPlay.dmg，版本 1.1.3。DMG 是 Mac 应用。安卓系统本身在第一次打开时下载。

下载 Mac 版 SiliconPlay

文件到手之后

  1. 打开 DMG，把 SiliconPlay 拖进应用程序。
  2. 打开 SiliconPlay。第一次运行会接受 Android SDK 许可，并下载 Apple 芯片模拟器、platform-tools 和 Play arm64 镜像，除非你已经有包含 emulator、adb 和 sdkmanager 的 SDK。
  3. Android 16 平板起来之后（1920×1080、320 dpi、横屏），登录 Google Play，或安装一个 APK。

你需要什么

  • 一台 Apple 芯片 Mac，M1 到 M6，包括 Pro、Max 和 Ultra。
  • 已在 macOS Tahoe 和 macOS 27 Golden Gate 上试过。其他版本可以试，然后告诉我发生了什么。
  • 不兼容 Intel Macs。

快捷键，Cmd+I 排第一

  • Cmd+I 在安卓已经运行时安装一个 APK。菜单里写的是 Command-I。拖放是同一种安装。
  • F12 或 Command-K 在打字和游戏键之间切换。
  • F10 是对话框需要手指时的直接触摸。
  • Command-Shift-G 显示或隐藏屏幕上的按钮。
  • Shift-Escape 松开卡住的虚拟手指。
  • Escape 退出全屏。全屏之外，画面有焦点时它是安卓的返回。

如果因为缺少 JDK 而停住，macOS 显示的是 /usr/bin/java 这个占位程序。提示指向 brew install openjdk@17。装上之后再跑一遍软件包步骤。更长的说明在博客，各工具的位置在 对比页.
