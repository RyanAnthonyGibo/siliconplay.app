Mac安卓模拟器快捷键：SiliconPlay 的键盘清单

作者： Ryan Gibo · 2026年10月27日

这是 SiliconPlay 在 Mac 上的键盘快捷键清单，取自软件本身（version 1.0.0, build 2），另外 Command-I 是我单独核对过的。我没有用别的模拟器的快捷键去填空，缺的组合也没有编造。下面没写出来的，就是我没法核实的，所以不放在这里。

SiliconPlay 只给 Apple Silicon：M1、M2、M3、M4、M5，以及这条产品线里更新的芯片。它在 Apple Silicon 的 ARM 核心上原生运行，从 M1 到 M5 以及更新的芯片。我在 macOS Tahoe 上试过。如果别的 macOS 版本表现不同，请 告诉我。

按键会进到哪里

点一下安卓画面，键盘才会进入键位。用 Command 键的菜单快捷键留在 macOS，不会被打进游戏。文本框有焦点时，工具栏变成 Typing，然后键盘作为文字进入安卓。

同一版本的 Shortcuts 列表还写出了这些动作，但我没有可以抄下来的组合：启动或停止选中的实例，切换全屏，退出全屏预览，保存截图，开始或停止录屏，编辑键位，在直接触摸和已映射按键之间切换，显示或隐藏安卓按钮，以及在正在运行的实例之间同步输入。每个名称旁边的键是菜单画出来的。这个版本里它不是一条单独可读的字符串，所以我不会编。请打开软件里的 Shortcuts and limits，看你这台电脑上的组合。

如果你还没改过，默认键位是这样

在键位生效之前，Game keys 帮不上什么忙。通用预设是 MMORPG (WASD)。它不绑某一款游戏。先套用，再移动按钮。完整的编辑步骤在 Mac 上的按键映射。那个文件里的绑定是：

接受分游戏预设之后，它会换掉这一套。例如 Minecraft 的预设用 left click 来 break，用 E 打开 inventory，而不是 J 和 M。在你接受建议之前，直接触摸保持打开，这些 Game keys 不会被加载。

问题

用什么在打字和游戏按键之间切换？

F12 或 Command-K。Game keys 使用键位。Typing 把键盘送进安卓。文本框会自己切到 Typing。

Escape 是做什么的？

它退出全屏。窗口不是全屏时，只要画面有焦点，Escape 就是 Android Back。Shift-Escape 松开每一根虚拟手指。正在改绑时，Escape 取消这次按键抓取。

这些就是软件里的全部快捷键吗？

Command-I 会导入 APK 并安装到安卓里。表里其余各项，是 1.0.0 帮助文字写明的全部组合，再加上默认键位。Shortcuts 列表里还有几个动作有名字，但这个版本没有可读的按键字符串。那些组合请到软件里查看。

哪些 Mac 能用？

Apple Silicon 的 Mac：M1、M2、M3、M4、M5，包括 Pro、Max、Ultra。
