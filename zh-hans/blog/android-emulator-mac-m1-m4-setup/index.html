Mac M1、M4 安卓模拟器：一步步安装教程

作者： Ryan Gibo · 2026年10月28日

搜索“Mac M1 安卓模拟器”或“Mac M4 安卓模拟器”，很多结果写于 Apple Silicon 之前。这里是简短、最新的版本：用我为 Apple Silicon 开发的 SiliconPlay，在 M 系列芯片的 Mac 上运行安卓游戏和应用。

你安装的是什么

SiliconPlay 底层运行的是 Google 官方的 Android Emulator，原生跑在 Mac 的 ARM 核心上。外面这层 Mac 应用，也就是界面和操控映射，是我从零写的。它只为 Apple Silicon 打造，支持 M1 到 M5，我在 macOS Tahoe 上做过测试。

你需要什么

  • 一台搭载 M1、M2、M3、M4 或 M5 芯片的 Mac（包括 Pro、Max 和 Ultra）。
  • macOS Tahoe。这是我测试过的版本。
  • 一个 Google 账号，如果你想从 Google Play 安装。

安装步骤

  1. 下载 SiliconPlay.dmg。
  2. 打开 DMG，把 SiliconPlay 拖到“应用程序”。
  3. 打开 SiliconPlay，启动 Android。
  4. 登录 Google Play，安装你的游戏和应用。要安装 APK 文件，按 Command-I。
  5. 点击 Android 画面。默认是直接触控。想用键盘玩，就接受 SiliconPlay 为你的游戏推荐的预设，或者套用 MMORPG (WASD) 后挪动按钮。

下载 Mac 版 SiliconPlay

先记住这几个快捷键

  • Command-I：导入 APK 并安装到 Android。
  • F12 或 Command-K：在 Typing 和 Game keys 之间切换。
  • Command-Shift-G：显示或隐藏屏幕上的游戏按钮。
  • Escape：退出全屏。不在全屏时，它是 Android 的返回键。
  • Shift-Escape：松开所有虚拟手指。

M1 和 M4 有什么不同？

从 M1 到 M5，每块芯片上的应用都一样。我没有发布按芯片的跑分，所以不会给你 M1 或 M4 的数字。新芯片余量更大，在重度 3D 游戏里差别最明显。如果游戏卡顿，先调低游戏里的画质设置。没有 ARM 版本的应用在哪块芯片上都跑不了，不过现在大多数应用都带 ARM 版本。

问题

Mac M1 能用吗？

能。M1、M2、M3、M4 和 M5 都行，包括 Pro、Max 和 Ultra。

需要哪个版本的 macOS？

我在 macOS Tahoe 上测试过 SiliconPlay。如果其他版本表现不同，请告诉我。

这是 Google 的模拟器吗？

底层是：Google 官方的 Android Emulator。界面和操控映射是 SiliconPlay 自己的，从零写成。

需要 root 吗？

不需要。root 是可选的，默认关闭，留给需要它的开发者。
