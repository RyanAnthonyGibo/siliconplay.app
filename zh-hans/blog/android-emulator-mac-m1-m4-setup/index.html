Mac M1、M4 安卓模拟器：一步步安装教程

作者： Ryan Gibo · 2026年10月28日

搜索“Mac M1 安卓模拟器”或“Mac M4 安卓模拟器”，很多结果写于 Apple Silicon 之前。这里是简短、最新的版本：用我为 Apple Silicon 开发的 SiliconPlay，在 M 系列芯片的 Mac 上运行安卓游戏和应用。

你安装的是什么

SiliconPlay 底层运行的是 Google 官方的 Android Emulator，原生跑在 Mac 的 ARM 核心上。外面这层 Mac 应用，也就是界面和操控映射，是我从零写的。它只为 Apple Silicon 打造，支持 M1 到 M6，我在 macOS Tahoe 和 macOS 27 Golden Gate 上做过测试。

你需要什么

  • 一台搭载 M1–M6 芯片的 Mac（包括 Pro、Max 和 Ultra）。
  • macOS Tahoe 和 macOS 27 Golden Gate。这是我测试过的版本。
  • 一个 Google 账号，如果你想从 Google Play 安装。

安装步骤

  1. 下载 SiliconPlay.dmg。
  2. 打开 DMG，把 SiliconPlay 拖到“应用程序”。
  3. 打开 SiliconPlay，启动 Android。
  4. 登录 Google Play，安装你的游戏和应用。要安装 APK 文件，按 Command-I。
  5. 点击 Android 画面。默认是直接触控。想用键盘玩，就接受 SiliconPlay 为你的游戏推荐的预设，或者套用 MMORPG (WASD) 后挪动按钮。

下载 Mac 版 SiliconPlay

先记住这几个快捷键

  • Command-I：导入 APK 并安装到 Android。
  • F12 或 Command-K：在 Typing 和 Game keys 之间切换。
  • Command-Shift-G：显示或隐藏屏幕上的游戏按钮。
  • Escape：退出全屏。不在全屏时，它是 Android 的返回键。
  • Shift-Escape：松开所有虚拟手指。

M1 和 M4 有什么不同？

从 M1 到 M6，每块芯片上的应用都一样。我没有发布按芯片的跑分，所以不会给你 M1 或 M4 的数字。新芯片余量更大，在重度 3D 游戏里差别最明显。如果游戏卡顿，先调低游戏里的画质设置。没有 ARM 版本的应用在哪块芯片上都跑不了，不过现在大多数应用都带 ARM 版本。

问题

Mac M1 能用吗？

能。M1–M6 都行，包括 Pro、Max 和 Ultra。

需要哪个版本的 macOS？

我在 macOS Tahoe 和 macOS 27 Golden Gate 上测试过 SiliconPlay。如果其他版本表现不同，请告诉我。

这是 Google 的模拟器吗？

底层是：Google 官方的 Android Emulator。界面和操控映射是 SiliconPlay 自己的，从零写成。

需要 root 吗？

不需要。root 是可选的，默认关闭，留给需要它的开发者。

短步骤没写的部分

2026 年 11 月 12 日更新。SiliconPlay 不兼容 Intel Macs。支持的是 Apple silicon，M1 到 M6，包括 Pro、Max 和 Ultra。我在 macOS Tahoe 和 macOS 27 Golden Gate 上测试过。其他 macOS 版本可以试，然后写到 siliconplay.app@gmail.com。

DMG 里没有模拟器，也没有系统映像。第一次启动会接受 Android SDK 许可，然后下载 command-line tools、Apple silicon 模拟器、platform-tools（adb 在这里）和 Play arm64 映像。平板是横向，1920×1080，320 dpi，关闭自动旋转，名字是 Android 16 Tablet。如果已有的 SDK 里包含 emulator、adb 和 sdkmanager，就指向那个文件夹。

如果因为没有 JDK 而停下，macOS 给你看的是 /usr/bin/java 这个存根。提示指向 brew install openjdk@17。装上之后再跑一次软件包步骤。

Cmd+I（菜单里是 Command-I）在实例运行时安装一个 APK。拖放是同一件事。这一版不安装拆分 APK 和 XAPK。没有 ARM64 库的包不会运行。Play 商店在 Play 映像上。密码不会进到 Mac 应用。那个映像拒绝 adb root。Root 是另一台平板，在 Google APIs 映像上，没有商店。

指望键盘之前，先点 Android 画面。直接触摸是默认。键位在你接受之前不会加载。通用预设是 MMORPG (WASD)。F12 或 Command-K 在打字和游戏键之间切换。F10 回到手指。Command-Shift-G 显示或隐藏按钮。Shift-Escape 松开所有虚拟手指。Escape 退出全屏。

我没有按芯片公布帧率。我肯写出的唯一数字来自一台 M3 Max 的 MacBook Pro：一款吃重的 3D 游戏最高 60 fps，渲染最高 2560×1440，按键到游戏 7–43 毫秒。游戏卡的话，先降它自己的画质。长指南我用英文维护，在 博客。
