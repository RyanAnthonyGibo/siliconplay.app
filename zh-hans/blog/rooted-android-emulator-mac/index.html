给 Apple Silicon 上的开发者用的、可以 root 的安卓模拟器

作者： Ryan Gibo · 2026年10月27日

如果只是想看一个 APK 能不能跑，把整套 IDE 打开会多出不少步骤。SiliconPlay 是放在一台真实安卓平板前面的小型 Mac 软件：ARM64、Android 16、Apple Silicon。我是 Ryan，这款软件是我从零写的。底层用的是官方 Android Emulator。许可声明里写着这套模拟器，以及随它而来的 SDK 组件。

它只面向 Apple Silicon，从 M1 到 M5，以及这条产品线里更新的芯片，包括 Pro、Max 和 Ultra。它在 Apple Silicon 的 ARM 核心上原生运行，从 M1 到 M5 以及更新的芯片。到目前为止，我只在 macOS Tahoe 上测试过。如果你试了别的 macOS 版本，把结果 发给我。我宁可听到实情，也不想靠猜。

你实际拿到的是什么

下载包里没有 Google 的模拟器，也没有系统镜像。第一次运行会请你下载安卓并开始。这一步会在这台 Mac 上接受 Android SDK 许可，然后把 Google 的 command-line tools、Apple silicon 模拟器、platform-tools，以及 Play 的 arm64 系统镜像，下载到你选定的 SDK 文件夹。软件会创建一台横屏平板，名字是 Android 16 Tablet，并在它自己的窗口里打开。默认平板是 1920×1080、320 dpi、横屏、关闭自动旋转，系统是 Android 16 Play 镜像。

等这套镜像就位，Google Play 才会出现。它不是我塞进软件里的商店。在安卓主屏幕上打开 Play Store 再登录。那个密码 SiliconPlay 看不到。如果你已经有带 emulator、adb 和 sdkmanager 的 SDK，可以把软件指到那个文件夹，不必再下一份。

如果因为 macOS 没有 JDK 而停住，软件会直接说明。/usr/bin/java 在 macOS 上只是一个 stub。软件里的提示指向 brew install openjdk@17，然后再把安装组件那一步重跑一次。

不用守在 IDE 里也能装 APK

先把实例启动，再安装。然后拖入一个 .apk 文件，或按 Command-I 导入 APK 并安装。这个版本不安装 Split APK 和 XAPK 压缩包，所以只有这些格式的包装不进去。用来确认“我的构建装上了没有、打开了没有”，这已经够了。你点应用的时候，不必让 Android Studio 一直开着。

也可以用 adb 安装。这样复制过去的文件会到 /sdcard/SiliconPlay。这些镜像不会把主机上的文件夹挂成一块实时磁盘，所以不要指望共享目录自己出现在安卓里面。

Pro Mode 在你打开之前是关的。它在工具栏、View 菜单和 Settings 里。关掉时，主窗口是 Start、Stop 和 Create New Instance。打开后，主窗口还会显示硬件、键位和诊断信息。

root 可选，而且默认关闭

root 是可选项，默认关闭。普通的 Play 平板请保持关闭。只有需要 adb root 时才打开。

做过 root 的平板用的是 Google APIs 镜像，因为 Play 镜像拒绝 adb root。那台平板不包含 Play Store。APIs 镜像会在你第一次创建这种平板时下载。如果既要登录 Play，又要 root，那就是两台平板，不是 Play 镜像上可以拨动的开关。

没有内核扩展，也没有事后要卸的后台服务。用完就把软件删掉。SDK 文件留在你选的那个 SDK 文件夹里。SiliconPlay 自己的文件在 ~/Library/Application Support/SiliconPlay。

如果你测的应用本身没有按键

直接触摸是默认状态，你自己做的界面通常就该这样。如果是在点一个游戏，屏幕键位和快捷键清单是剩下的另一半。

问题

必须 root 吗？

不用。root 是可选项，默认关闭。root 使用 Google APIs 镜像。Play 镜像拒绝 adb root，那台 root 过的平板也不带 Play Store。

怎么安装 APK？

先启动实例，再拖入 APK，或按 Command-I 导入。也可以用 adb 安装。这个版本不安装 Split APK 和 XAPK 压缩包。adb 复制的文件会到 /sdcard/SiliconPlay。

Android Studio 要一直开着吗？

不用。不用把整套 IDE 挡在前面，也能装上 APK 再试。软件会下载官方模拟器和 Play 的 arm64 镜像，或者使用你已经有的 SDK。

哪些 Mac，哪个 macOS？

只有 Apple Silicon：M1、M2、M3、M4、M5 以及更新的芯片，包括 Pro、Max 和 Ultra。在 Apple Silicon 上原生运行。到目前为止只在 macOS Tahoe 上测试过。
