Mac安卓模拟器的按键映射：屏幕按钮和分游戏布局

作者： Ryan Gibo · 2026年10月27日

多数安卓游戏认的是手指。Mac 上你已经有键盘、鼠标，也许还有手柄，一直点触控板很快会烦。SiliconPlay 把按钮铺在游戏画面上，再把这些按钮绑到按键上。在这款 Mac安卓模拟器里，按键映射就是这件事：一颗键或一根摇杆，变成你指定位置上的一次触摸。

SiliconPlay 只在 Apple Silicon 上运行，从 M1 到 M5，以及这条产品线里更新的芯片。它在 Apple Silicon 的 ARM 核心上原生运行，从 M1 到 M5 以及更新的芯片。我在 macOS Tahoe 上试过。如果你用的是别的 macOS 版本，把情况 告诉我。

想用按键之前，先是直接触摸

直接触摸是默认状态。指针就是一根手指，菜单、商店，以及没有键位的应用都适合这样。当前面是一款已知游戏时，SiliconPlay 可以给出社区预设。这个预设会一直关着，直到你接受。软件打开本身不会装上任何键位。

点一下安卓画面，键盘才会进到键位。如果焦点在文本框里，工具栏会写成 Typing，按键进入安卓，而不是去按那些按钮。F12 或 Command-K 在 Typing 和 Game keys 之间切换。用 Command 键的菜单快捷键仍留给 macOS。

SiliconPlay 窗口有焦点时，按键一样有效。软件第一次跟着模拟器自己的窗口走时，macOS 会请求 Accessibility。在你允许之前，让 SiliconPlay 窗口保持焦点，按键仍然能落到游戏上。

默认布局：MMORPG (WASD)

软件自带的通用布局名叫 MMORPG (WASD)。它不绑定某个 package，所以不会自动推荐。你可以把它套到任何游戏上，再把对不齐的地方改掉。摇杆先点在自己按钮的中心，按住方向键时向外滑。松开后，它滑回中心。

这份预设上的说明就是让你到编辑器里调整。把这些位置当成起点。它们是游戏画面上的比例，从 0 到 1，原点在左上角，所以窗口变大变小时会跟着缩放。

把按钮挪到游戏画面上

Edit layout 会打开键位编辑器。拖动按钮来移动。点一下按钮，可以改绑键盘或鼠标按键。拖动 gold dot 来改大小。你可以加一个 WASD 摇杆、镜头拖动、点按、长按、滑动或重复。Done 会保存。Cancel 把配置恢复到你打开编辑器时的样子。如果正在抓取按键，Escape 会取消这次抓取。

单独的模拟器窗口上有一颗玻璃气泡，它会跟着窗口走。拖动气泡来移动。点它可以看到叠加层、不透明度、大小、编辑和重置。这个位置记在配置里。Command-Shift-G 用来开关叠加层。画面上的空白处仍然会点到游戏。

F10 会切到直接触摸。菜单要的是真的手指，而不是已经映射好的按钮时，这条路更简单。如果有虚拟手指卡住没松开，Shift-Escape 会把每一根都放开。

手柄按的是同一批按钮

一颗屏幕按钮可以同时听不止一种输入。默认布局里，skill 1 是数字键 1 和 gamepad X，跳跃是 Space 和 gamepad B。重新绑定时，还可以绑 face buttons、shoulders、triggers、D-pad、menu 和 options。手柄不是第二套操作。它按下去的，就是键盘在按的那些屏幕按钮。

按游戏分开的布局

有些应用有自己的预设，按 package 对上。那款游戏在前面时，SiliconPlay 会提出来，然后等你。先接受，再把没对准画面的按钮拖过去。这些文件里的说法是社区预设。

Minecraft 很能说明什么叫“不是那套通用布局”。它的预设用 WASD 移动，左键用来破坏，右键用来使用，Space 跳跃，E 打开物品栏，1 到 3 是快捷栏，鼠标右键用来转动视角。按钮散在不同角落的游戏，需要的是这种调整，而不是沿底边排一排 MMORPG 按钮。

同一个版本里还有 Genshin Impact、Roblox、Call of Duty Mobile 和 Clash of Clans 的预设。我不会假装一套布局能套住所有这些游戏。接受建议，玩一会儿，再把按钮挪到位。

到网上找键位

靠得住的是软件里的那一份。如果你找到别人发出来的布局，它必须是 SiliconPlay 的键位文件：format id 为 stardroid.keymap 的 JSON。不是这个格式的合法 JSON，会被拒绝。共享文件里的位置是按别人的屏幕画的，所以打开编辑器，把按钮对齐到你自己的画面上。

Pro Mode 在工具栏、View 菜单和 Settings 里。打开之后，主窗口会显示硬件、键位和诊断信息。你不打开，它就一直关着。模拟器窗口上的气泡仍然有编辑、叠加层、不透明度、大小和重置。

问题

SiliconPlay 能在哪些 Mac 上运行？

Apple Silicon 的 Mac：M1、M2、M3、M4、M5，包括 Pro、Max、Ultra。

必须使用按键映射吗？

不用。直接触摸是默认状态。建议的预设会一直关着，直到你接受它。

能用手柄吗？

能。手柄按下的是和键盘相同的屏幕按钮。MMORPG 布局里，若干技能和跳跃已经绑好了。

去哪里找我这个游戏的键位？

用软件给出的预设，或者自己套用 MMORPG (WASD) 再改。别处来的文件必须是合法的 stardroid.keymap JSON。
