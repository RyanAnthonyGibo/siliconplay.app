What’s new in SiliconPlay 1.1.2

Version 1.1.2 (build 5) · Apple Silicon M1–M6 · 20 November 2026

SiliconPlay 1.1.2 is a free update to the Android emulator for Apple Silicon Macs. It now keeps itself up to date, opens on the full main window, and has a new instance list that does what you expect when you click it.

Download SiliconPlay 1.1.2 for Mac

1.1.2: fluid scrolling and fixes from your logs

Version 1.1.2 (build 5) was built from logs that users sent in, and it adds new controls for scrolling and zoom.

  • More reliable Android startup on macOS Sequoia and earlier. When the newest Android Emulator doesn’t start cleanly there, SiliconPlay uses a tested emulator version next to it.
  • If graphics errors keep showing up while Android starts, SiliconPlay switches to a safer graphics mode by itself and tells you.
  • No more false “port in use” error when Android simply stopped.
  • New Auto, Pinch and Scroll modes for the mouse wheel and trackpad, in the radial menu. Auto scrolls in apps and pinch-zooms in games.
  • Trackpad scrolling is fluid and follows your fingers from the moment Android starts, and lists keep gliding when you let go.
  • Scroll and pinch sensitivity: the Speed wedge in the radial menu goes from 0.25× to 3×, and Settings has a slider for each, with Reset to go back to 1×.
  • Stopping an instance is more stable: SiliconPlay lets Android shut down on its own before closing it.

1.1.1: more reliable Android startup

Version 1.1.1 (build 4) is a fix update. It should help Android start on Macs where it stopped during boot with “could not start”, especially on macOS Sequoia and earlier, or after the Android Emulator updated itself to a newer version.

  • Before it starts Android, SiliconPlay reads the Android Emulator version. On macOS Sequoia and earlier, with an emulator newer than the one SiliconPlay was tested with, it starts in OpenGL ES graphics mode.
  • If Android stops during boot, SiliconPlay tries safer graphics modes one after another instead of giving up.
  • If Android still can’t start, the message shows the real reason, and Copy Diagnostics copies the details so you can send them to me. Logs are in ~/Library/Logs/SiliconPlay.

Added in 1.1.0:

Automatic updates

  • SiliconPlay checks for a new version about once a day. When one is out, it tells you once. Later hides that version until the next one.
  • SiliconPlay → Check for Updates… checks right away. To stop the daily check, turn off Check for updates automatically in Settings.
  • Download saves the disk image in your Downloads folder and opens it. The app is signed with a Developer ID and notarized by Apple.

Main window and instance list

  • The app opens on the full main window, with every control visible.
  • A click selects an instance, including the one that is already selected.
  • Right-click any instance, the selected one too, for Start, Stop, Settings…, Rename…, Duplicate, Show in Finder and Delete.
  • Double-click an instance to open its settings.
  • Game presets with mouse look no longer block clicks, typing or scrolling in SiliconPlay’s own windows.

Pinch zoom with the scroll wheel

  • In Android apps, the scroll wheel now pinch-zooms at the cursor, like two fingers on a touchscreen. Maps and game cameras zoom the way they do on a phone. Hold Shift to scroll a list instead.
  • You can change this in Settings → Scroll wheel: Scroll the page or Camera look. In those modes, hold Option to pinch.

How to update from 1.0

  1. Download SiliconPlay 1.1.2 and open the disk image.
  2. Quit SiliconPlay, then drag the new app into Applications and replace the old one. Your instances are stored outside the app, so they stay.
  3. If keyboard controls stop working, open System Settings → Privacy & Security → Accessibility and allow SiliconPlay again. macOS can ask again after an app is replaced.
  4. From now on, new versions are offered inside the app.

Which Macs

SiliconPlay is exclusive to Macs with Apple Silicon, M1 to M6. It is not compatible with Intel Macs. Version 1.1.0 was tested on macOS Tahoe and macOS 27 Golden Gate.
