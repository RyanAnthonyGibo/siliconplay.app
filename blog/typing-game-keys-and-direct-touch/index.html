Typing, game keys, and direct touch: where your keys go

By Ryan Gibo · 3 November 2026

A key on a Mac can mean three different things once SiliconPlay is open, and the app will do exactly one of them. It will hand the key to Android as text. It will turn the key into a touch on a button you placed. Or it will keep the key as a Mac command and never send it to the game. Almost every “my keyboard does nothing” report is one of those three, chosen correctly, and surprising because the toolbar was showing a different mode than the one you remembered.

Direct touch is the start

Direct touch is the default. The pointer is a finger. That is the right mode for a Play Store page, a login form you would rather click, a shop, or an app you are testing that has ordinary buttons. No keymap is loaded just because the app opened, and a community preset for a known game stays off until you accept it. Until you accept a suggestion, game keys are not in effect.

F10 switches to direct touch on purpose, including when you were in a mapped layout and a menu wants a real finger. Empty space on the picture still clicks the game when the overlay is up. The overlay is not a pane of glass over the whole window.

Click the image, or the keys have no target

Click the Android image so the keyboard goes to the keymap. Keys still work while the SiliconPlay window is focused. The first time the app follows the emulator’s own window, macOS asks for Accessibility. Until you allow that, keep the SiliconPlay window focused and the keys still land. If you deny Accessibility and then click the emulator window, macOS is doing what you asked: the follow does not happen. Focus the SiliconPlay window again. I wrote the longer version of that permission in when keys go to the wrong place.

Command-key menu shortcuts stay with macOS. They are not typed into the game. Command-I imports an APK. Command-K is the mode switch, shared with F12. Those chords never become the letters i or k inside Android.

Typing, and the field that switches for you

A focused text field switches the toolbar to Typing. In Typing, the keyboard goes to Android as text. That is how you enter a username, a chat line, or a search. You do not map WASD for that. You leave Game keys.

F12 or Command-K toggles Typing and Game keys. Game keys uses the keymap. Typing sends the keyboard to Android. If you are in a field and the letters are moving a character instead of filling the box, you are in Game keys. Press F12 or Command-K. If you are in a fight and the letters are appearing in a leftover chat box, you are in Typing. Same chord, the other way.

The field can switch you to Typing by itself. That is intentional. A game that opens a text box has asked for text. When you close the box, check the toolbar before you assume the keymap is back. If it still says Typing, press F12 or Command-K.

Game keys need a layout

Game keys do nothing useful until a keymap is on. Accept the preset the app offers for the game in front, or apply MMORPG (WASD) yourself and move the buttons. The generic preset is not tied to one package, so it will not appear on its own. Positions are fractions of the game picture, from 0 to 1, origin at the top left, so they scale when the window changes size. Treat the shipped positions as a starting point.

Edit layout: drag a button to move it, click it to rebind a key or a mouse button, drag the gold dot to resize. You can add a WASD joystick, a camera drag, a tap, a long-press, a swipe, or a repeat. Done saves. Cancel puts the profile back to how it was when you opened Edit. Escape, while rebinding, cancels the “press a key or mouse button” capture. It does not save, and it does not send Back in that moment.

On the emulator window, a glass bubble follows the window. Drag the bubble to move it. Click it for the overlay, opacity, size, edit, and reset. That spot is saved on the profile. Command-Shift-G shows or hides the on-screen game buttons. Hiding them does not delete the keymap.

The shortcut list, Command-I first

These are the chords version 1.0.0 states in words. I confirmed Command-I separately. If a chord is not here, I could not verify it from that build, so it is not here.

Mode and overlay shortcuts in SiliconPlay 1.0.0
KeysWhat changes
Command-IImport an APK and install it into Android. This is a Mac command, not a game key.
F12, or Command-KToggle Typing and Game keys.
Command-Shift-GShow or hide the on-screen game-button overlay.
EscapeLeave fullscreen. When the window is not fullscreen, Escape is Android Back while the display is focused.
Shift-EscapeRelease every virtual finger.
F10Switch to direct touch.
Escape, while rebindingCancel the key or mouse capture.

Escape does two jobs, and they depend on fullscreen. In fullscreen it leaves fullscreen. Outside fullscreen, with the display focused, it is Android Back. Shift-Escape is the one that lets go of every virtual finger if a button stayed down. People mix those up and then think Back is broken. Read the row again before you rebind Escape.

A controller is not a third mode

A chip can listen for a key and a gamepad button at the same time. In the default MMORPG layout, skill 1 is both the 1 key and gamepad X, jump is both Space and gamepad B, and skills 2, 4, and 6 also have a gamepad button. The controller presses the same on-screen buttons the keyboard does. It is not a separate control scheme with its own mode in the toolbar. If Game keys are off, the controller is not secretly in a different mode. Turn Game keys on, with a layout loaded, or stay on direct touch and use the pointer.

A short path when the mode feels wrong

  1. Look at the toolbar. It says Typing or it is on game keys. Believe the toolbar.
  2. If you wanted text, press F12 or Command-K until it says Typing, and click the field.
  3. If you wanted the keymap, press F12 or Command-K the other way, and confirm you accepted a preset or applied MMORPG (WASD).
  4. If a finger is stuck down, press Shift-Escape.
  5. If a menu wants a real tap, press F10.
  6. If you needed to install a file in the middle of all this, press Command-I. It does not depend on the mode.

Pro Mode does not change these chords. It shows hardware, keymaps, and diagnostics on the main window when you turn it on from the toolbar, the View menu, or Settings. The bubble on the emulator window still has edit, overlay, opacity, size, and reset either way.
